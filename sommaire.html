gameboy3

Écrire une cartouche Game Boy en C++ — tout ce que contient le dépôt, à un seul endroit.

Pour démarrer Double-cliquer lancer.bat, ou dans un terminal : node demarrer.mjs. Le navigateur s'ouvre tout seul sur l'atelier.

Utiliser l'atelier

Les deux pages qui tournent dans le navigateur, une fois l'atelier démarré.

🎮 L'atelier complet Création (tuiles, airs, couleurs, modèles), Code, Apprendre et Machine — les quatre modes, dans une seule page. 📘 Apprendre — le parcours Les leçons et le cours réunis en une seule suite de 587 étapes, en 25 chapitres, un #include nouveau à la fois : du programme qui ne fait rien jusqu'à un jeu complet.

Apprendre : le parcours, à lire

La même matière, en texte, pour lire ou chercher sans lancer l'atelier.

📄 TUTORIELS.md 80 leçons complètes, code + explication, du niveau 1 au niveau 10. 🧭 PARCOURS.md Les leçons regroupées par objectif : le chemin pas à pas vers Tetris, Mario, et neuf autres genres de jeu. 📕 tutoriel.pdf Les 80 leçons en PDF, une page chacune, prêtes à imprimer. 📚 livret.html La version détaillée à l'écran : chaque leçon, étape par étape, avec ses captures. 🗂 livrets/ Un livret PDF et HTML par leçon (une par une), avec l'exécution photographiée. 🔀 Passer d'un écran à l'autre Fiche à part sur les changements d'écran — enum, switch, machine à états.

Le projet, en bref

Pour présenter ou évaluer le dépôt sans le parcourir en entier.

📖 LISEZMOI.md Le README complet : installation, langage, fonctions de la console, réglages. 💎 valorisation.html Ce que le projet est, ce qui le rend rare, comparé à PICO-8, et son volume. 🕒 CHANGEMENTS.md L'historique : ce que chaque passe de travail a ajouté ou corrigé.
