# game_boy_emulateur

**gameboy3** : écrire une cartouche Game Boy en C++, la voir tourner dans un émulateur, et apprendre à programmer pas à pas.

Toute la documentation est en français, dans **[LISEZMOI.md](LISEZMOI.md)** : installer et démarrer, le langage, les fonctions de la console et leurs `#include`, le parcours « Apprendre », les outils, les vérifications.

## Démarrer

Double-cliquer **`lancer.bat`** : l'atelier s'ouvre dans le navigateur (`http://localhost:8000`). Node.js 18 ou plus est nécessaire ; s'il manque, `lancer.bat` propose de l'installer.
