0.29. Revenir au départ avec va_a

Le 0.28, plus une ligne : va_a(x, y, …, 0, 0) ramène la lettre au coin, sans compter les pas du retour.

1. Ce qu’il faut comprendre

C’est le 0.28, plus une ligne : le retour à (0, 0).

Ce qui est nouveau ici : rien qu’une autre arrivée. Pour revenir, on ne calcule pas « -10 et -5 » : on dit simplement où : 0, 0.

Le chemin du retour suit la même règle : en diagonale tant que les deux axes avancent, de (10, 5) à (5, 0), puis tout droit jusqu’en (0, 0).

2. Le programme, morceau par morceau

Le programme entier de la leçon, découpé comme l’œil le lit. Il fait 1695 octets de cartouche.

1. une variable — x

uint8_t x = 0;        // la COLONNE de la lettre

2. une variable — y

uint8_t y = 0;        // la LIGNE de la lettre

3. le point d’entrée : c’est ici que la console arrive

int main() {
  va_a(x, y, ALPHABET[0], 10, 5);   // l'aller (le 0.28) : jusqu'en (10, 5)

  // La ligne ajoutée : l'arrivée est le coin (0, 0).
  //   de (10, 5), en diagonale jusqu'en (5, 0), puis tout droit jusqu'en (0, 0)
  va_a(x, y, ALPHABET[0], 0, 0);

  nombre(0, 17, x);     // 000
  nombre(4, 17, y);     // 000

  while (true) {
    image();
  }
}

3. Ce qui se passe, étape par étape

La cartouche a été compilée et exécutée pour de bon ; voici son écran aux instants qui comptent. Une image identique à la précédente n’est pas montrée — un programme qui ne bouge pas n’a qu’une seule image, et c’est la vérité sur ce programme.

4. Ce qu’on doit voir

Le A va jusqu’en (10, 5), puis revient au coin (0, 0), en biais puis tout droit.

5. Ce que la console répond

Ces contrôles ne sont pas décoratifs : ce sont ceux que verifier-tuto.mjs exige de cette leçon. Ils viennent d’être joués, et voici ce qu’ils ont mesuré.

  • l’aller jusqu’en (10, 5)
  • le retour en biais : (7, 2), puis tout droit : (3, 0)
  • revenu en (0, 0) ; x et y valent 0
