33. Une vitesse qui monte

Accélérer, c’est une variable de plus.

1. Ce qu’il faut comprendre

Un objet qui accélère, c’est une vitesse qui monte. Tout ce qui suit — le saut, la pesanteur — n’est que cela, avec un signe en plus.

Elle ne montera pourtant jamais jusqu’à 5 : plus le caillou va vite, plus tôt il touche le bas, et la chute suivante repart à 1. Le plafond écrit dans le code n’est pas celui qu’on observe — c’est le genre d’écart qu’on ne voit qu’en faisant tourner.

Pourquoi depuis et non images() % 20 == 0. Les deux paraissent équivalents, et ils ne le sont pas. Tester un multiple suppose que la boucle tourne exactement une fois par image ; dès que le corps s’alourdit, un tour franchit deux images d’un coup, le multiple est enjambé, et l’accélération n’arrive jamais.

Un compteur incrémenté à chaque tour et comparé avec >= ne peut pas rater son échéance. C’est la forme à prendre par défaut.

2. Le programme, morceau par morceau

Le programme entier de la leçon, découpé comme l’œil le lit. Il fait 1416 octets de cartouche.

1. un dessin — CAILLOU

Tuile CAILLOU = {
  "..####..", ".######.", "########", "########",
  "########", "########", ".######.", "..####..",
};

2. le point d’entrée : c’est ici que la console arrive

int main() {
  uint8_t y = 0;
  uint8_t vitesse = 1;
  uint8_t depuis = 0;

  while (true) {
    y += vitesse;
    if (y > 130) { y = 0; vitesse = 1; depuis = 0; }

    depuis++;
    if (depuis >= 20) { depuis = 0; if (vitesse < 5) vitesse++; }

    sprite(0, 76, y, CAILLOU);
    image();
  }
}

3. Ce qui se passe, étape par étape

La cartouche a été compilée et exécutée pour de bon ; voici son écran aux instants qui comptent. Une image identique à la précédente n’est pas montrée — un programme qui ne bouge pas n’a qu’une seule image, et c’est la vérité sur ce programme.

4. Ce qu’on doit voir

Un caillou qui tombe de plus en plus vite, et recommence.

5. Ce que la console répond

Ces contrôles ne sont pas décoratifs : ce sont ceux que verifier-tuto.mjs exige de cette leçon. Ils viennent d’être joués, et voici ce qu’ils ont mesuré.

  • la vitesse monte (jusqu’à 4)
  • sans dépasser le plafond écrit
  • le caillou parcourt tout l’écran (y jusqu’à 128)
  • et il recommence en haut
