0.53.1. Deux lettres, deux carrés — de base, ailleurs

Deux autres lettres, deux autres places : le C autour de (15, 4), le D autour de (14, 12).

1. Ce qu’il faut comprendre

C’est le 0.53, avec deux autres lettres, le C et le D, à deux places libres de l’écran : (15, 4) et (14, 12).

C’est la version de base : la deuxième place, seule. Le 0.53.2 met les deux ensemble.

2. Le programme, morceau par morceau

Le programme entier de la leçon, découpé comme l’œil le lit. Il fait 2113 octets de cartouche.

1. le point d’entrée : c’est ici que la console arrive

int main() {
  carre(15, 4, ALPHABET[2], 1, 1, 250, 1);     // le C, en haut à droite
  carre(14, 12, ALPHABET[3], 3, -1, 100, 1);   // le D, en bas à droite

  while (true) {
    image();
  }
}

3. Ce qui se passe, étape par étape

La cartouche a été compilée et exécutée pour de bon ; voici son écran aux instants qui comptent. Une image identique à la précédente n’est pas montrée — un programme qui ne bouge pas n’a qu’une seule image, et c’est la vérité sur ce programme.

4. Ce qu’on doit voir

Le C fait un petit carré en haut à droite, puis le D un grand en bas à droite.

5. Ce que la console répond

Ces contrôles ne sont pas décoratifs : ce sont ceux que verifier-tuto.mjs exige de cette leçon. Ils viennent d’être joués, et voici ce qu’ils ont mesuré.

  • le C finit en (15, 4) (15,4)
  • le D finit en (14, 12) (14,12)
