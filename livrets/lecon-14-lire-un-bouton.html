Chapitre 3 — Retenir, et réagir leçon 14 sur 143 difficulté 2 / 10

14. Lire un bouton

Réagir à la manette.

1. Ce qu’il faut comprendre

bouton(A) rend 1 tant que le bouton est enfoncé. Les huit noms existent : A B HAUT BAS GAUCHE DROITE START SELECT.

Ici on lit le niveau : tant que A est tenu, le texte change. C’est ce qu’on veut pour courir ou viser — mais pas pour un menu : c’est la leçon « le front » qui règle ce cas.

&&, || et ! s’écrivent comme en C++, et s’arrêtent dès que la réponse est connue : dans i < n && t[i] == 0, la case n’est pas lue si l’index est hors du tableau.

Les fonctions de cette leçon — et le tuto de chacune

  • #include <texte> → 0.0.2. La fonction texte() — écrire un mot
  • #include <bouton> → 0.65.5. La fonction bouton() — lire la manette

1. ce que le programme raconte de lui-même

#include <texte>    // écrit un texte à l’écran
#include <bouton>   // lit un bouton de la manette

2. le point d’entrée : c’est ici que la console arrive

int main() {
  texte(3, 5, "APPUIE SUR A");

  while (true) {
    image();

    if (bouton(A) && !bouton(B)) {
      texte(3, 5, "BRAVO       ");
    }

    if (bouton(B)) {
      texte(3, 5, "APPUIE SUR A");
    }
  }

  return 0;
}
