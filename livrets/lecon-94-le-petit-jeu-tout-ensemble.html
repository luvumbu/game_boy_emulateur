94. Le petit jeu : tout ensemble

Variables, conditions, boucles, tableaux, fonctions, struct : un vrai jeu, et rien d’autre.

1. Ce qu’il faut comprendre

Des objets tombent du ciel ; le panier (|#|) les attrape. Chaque objet attrapé rapporte un point ; chaque objet manqué coûte une vie. Toutes les notions du cours y sont, à leur place :

Variables : score, vies, la position du panier. Conditions : attrapé ou manqué ? partie finie ? Boucles : la boucle du jeu, et un for sur les objets. Tableau de struct : les trois Chute. Fonctions : lancer, attrape, dessinerPanier, dessinerScore. Méthode : tomber(). VBlank : le décor posé écran éteint, et chaque image n’écrit que ce qui a changé.

Un objet n’est jamais créé ni détruit : il est recyclé. Quand il arrive en bas, lancer(i) le renvoie en haut, à une colonne tirée au hasard. C’est la technique de presque tous les jeux Game Boy : un nombre fixe de places, qu’on réutilise.

attrape(i) est une fonction qui répond : l’objet est-il sur la ligne du panier, et entre ses deux bords ? Sa condition se lit comme la règle du jeu.

Le panier se redessine seulement s’il a bougé, le score seulement quand il change, et les objets un tour sur huit : c’est ce qui permet au panier de rester vif pendant que la pluie tombe.

Quand vies tombe à 0, on sort de la boucle du jeu par break, et le programme continue : « PERDU! ». Le while (true) de la fin garde l’écran affiché.

À toi : accélère la chute quand le score augmente (indice : remplace le 8 de attente == 8 par une variable qui diminue).

📖 Les mots de cette leçon — si tu débutes

  • accolades { } — Elles entourent un bloc : les lignes qui vont ensemble (le corps d’une fonction, d’une boucle, d’un « if »). Chaque « { » a son « } ».
  • affectation (=) — « x = 5; » : la boîte x prend la valeur 5. Ce n’est pas une égalité : c’est un rangement.
  • argument — Une valeur donnée à une fonction quand on l’appelle, entre ses parenthèses : dans texte(5, 8, "SALUT"), 5, 8 et "SALUT" sont les arguments.
  • bloc — Un groupe de lignes entre accolades { }, qui s’exécutent ensemble.
  • booléen (vrai / faux) — Le résultat d’une condition : vrai (1) ou faux (0). « true » veut dire vrai, « false » faux.
  • boucle — Des instructions qui se répètent : « while » (tant que…) ou « for » (pour un compteur qui va de… à…).
  • boucle du jeu — « while (true) { image(); … } » : ce qui se répète 60 fois par seconde, sans fin, pendant tout le jeu.
  • bouton() — Une fonction de la console qui dit si un bouton de la manette est enfoncé : 1 oui, 0 non. Les boutons : A, B, HAUT, BAS, GAUCHE, DROITE, START, SELECT.
  • break — Sort tout de suite de la boucle (ou du « switch ») où l’on est.
  • chaîne de caractères (texte) — Des lettres entre guillemets, "COMME CECI" : un texte pris tel quel. La police de la console n’a que des majuscules, sans accents.
  • commentaire (//) — Tout ce qui suit « // » jusqu’au bout de la ligne : une phrase pour l’humain, que la console ignore.
  • condition — Une question dont la réponse est vrai ou faux : « score > 10 », « bouton(A) ». On la teste avec « if » ou « while ».
  • constante (const) — Une valeur qui a un nom et ne change jamais : « const uint8_t VIES = 3; ».
  • continue — Passe directement au tour suivant de la boucle.
  • coordonnées — Deux nombres qui disent où : la colonne (vers la droite) puis la ligne (vers le bas), à partir de (0, 0) en haut à gauche.
  • else (sinon) — Ce que l’on fait quand la condition du « if » est fausse.
  • fonction — Un groupe d’instructions qui a un nom, qu’on lance en écrivant son nom et des parenthèses. Celles de la console (texte, poser…) sont toutes prêtes ; on peut écrire les siennes.
  • for — Une boucle qui compte : « for (uint8_t i = 0; i < 5; i++) » fait 5 tours, i valant 0, 1, 2, 3 puis 4.
  • hasard() — Une fonction de la console qui rend un nombre au hasard, de 0 à 255.
  • if (si) — Teste une condition : si elle est vraie, on fait le bloc qui suit.
  • image() — Attend l’image suivante. La console en montre 60 par seconde : c’est ce qui règle la vitesse d’un jeu.
  • #include — En haut du programme : « #include <texte> » demande la fonction texte() à la console ; « #include "fichier.cpp" » verse un de tes fichiers à cet endroit.
  • incrémenter (++) — « x++ » ou « x += 1 » : x augmente de 1. « x-- » : x diminue de 1.
  • indice — Le numéro d’une case dans un tableau, entre crochets : cases[3] est la quatrième case (on compte à partir de 0).
  • instruction — Un ordre donné à la console, terminé par un point-virgule : « texte(1, 1, "OK"); ».
  • main — « int main() { … } » : là où le programme commence. La console exécute d’abord la première ligne de main.
  • octet — Un nombre de 0 à 255 : la plus petite boîte de la mémoire. Une cartouche en a 32 768.
  • opérateurs de calcul — + plus, - moins, * fois, / divisé par (sans virgule : 7 / 2 donne 3), % le reste de la division (7 % 2 donne 1).
  • opérateurs de comparaison — == égal, != différent, < plus petit, > plus grand, <= plus petit ou égal, >= plus grand ou égal. Le résultat est vrai ou faux.
  • opérateurs logiques — && « et » (les deux doivent être vrais), || « ou » (un seul suffit), ! « pas ».
  • paramètre — Dans la définition d’une fonction, la boîte qui reçoit une valeur donnée à l’appel : dans « void f(uint8_t x) », x est un paramètre.
  • point-virgule (;) — Il termine une instruction, comme le point termine une phrase.
  • return — Termine la fonction et rend une valeur à celui qui l’a appelée.
  • struct — Un modèle qui regroupe plusieurs boîtes sous un nom : « struct Ennemi { uint8_t x; uint8_t y; }; ».
  • tableau — Une rangée de boîtes sous un même nom : « uint8_t cases[10]; » donne cases[0] à cases[9].
  • texte() — Écrit des lettres à l’écran, sur la grille de 20 colonnes et 18 lignes : texte(colonne, ligne, "MOT").
  • uint8_t — Le genre de nombre de cette console : un entier de 0 à 255 (un octet). Au-delà, il repart à 0.
  • variable — Une boîte avec un nom, dans la mémoire, qui retient un nombre qu’on peut lire et changer.
  • void — Devant une fonction : elle ne rend rien, elle agit seulement.
  • while (tant que) — Répète un bloc tant qu’une condition est vraie.

1. ce que le programme raconte de lui-même

// CE PROGRAMME : LE PETIT JEU. Des gouttes O tombent ; un panier |#| en bas
// les attrape. Chaque goutte attrapée = 1 point ; chaque goutte ratée = 1 vie en moins.
// À 0 vie : PERDU!
//
// Tout ce qu'on a vu sert ici : variables, conditions, boucles, tableaux,
// fonctions et struct.

#include <hasard>   // tire un nombre au hasard
#include <texte>    // écrit un texte à l’écran
#include <nombre>   // écrit un nombre en chiffres
#include <ecran>    // éteint ou rallume l’écran
#include <bouton>   // lit un bouton de la manette
#include <reste>    // a % b, sauf par 1, 2, 4, 8, 16… écrits en clair

2. une constante — COMBIEN

const uint8_t COMBIEN = 3;      // 3 gouttes à la fois.

3. une constante — SOL

const uint8_t SOL = 16;         // La ligne du panier.

4. un enregistrement — Chute

struct Chute {                  // Une goutte :
  uint8_t x;                    //   sa colonne,
  uint8_t y;                    //   sa ligne.

  void tomber() { y++; }        //   Méthode : descendre d'une ligne (y grandit vers le bas).
};

5. un tableau — pluie

Chute pluie[COMBIEN];           // Les 3 gouttes.

6. une variable — panier

uint8_t panier = 8;             // La colonne de la gauche du panier (il fait 3 cases).

7. une variable — ancienPanier

uint8_t ancienPanier = 8;       // Où le panier est dessiné.

8. une variable — score

uint8_t score = 0;

9. une variable — vies

uint8_t vies = 3;

10. une fonction — lancer()

void lancer(uint8_t i) {        // (Re)met la goutte i en haut, à une colonne au hasard.
  pluie[i].x = 1 + hasard() % 18;   // hasard() % 18 : 0 à 17 ; + 1 : colonnes 1 à 18.
  pluie[i].y = 2;                   // Elle repart de la ligne 2.
}

11. une fonction — attrape()

uint8_t attrape(uint8_t i) {    // Rend 1 si la goutte i tombe DANS le panier.
  return pluie[i].y == SOL && pluie[i].x >= panier && pluie[i].x <= panier + 2;
                                // Elle est à la ligne du panier ET dans ses 3 colonnes :
                                // panier, panier + 1 ou panier + 2.
                                // Exemple : panier = 8 → colonnes 8, 9, 10.
}

12. une fonction — dessinerPanier()

void dessinerPanier() {         // Déplace le panier à l'écran.
  texte(ancienPanier, SOL, "   ");  // 3 espaces : efface l'ancien panier,
  texte(panier, SOL, "|#|");        // dessine le nouveau,
  ancienPanier = panier;            // et retient où il est.
}

13. une fonction — dessinerScore()

void dessinerScore() {          // Réécrit le score et les vies en haut.
  nombre(7, 0, score);
  nombre(18, 0, vies, 1);
}

14. le point d’entrée : c’est ici que la console arrive

int main() {                    // Le jeu commence ici.
  ecran(0);                     // Préparation, écran éteint :
  texte(0, 0, "SCORE:");
  texte(12, 0, "VIES:");
  texte(0, 17, "GAUCHE    DROITE");
  for (uint8_t i = 0; i < COMBIEN; i++) {
    lancer(i);                  //   chaque goutte à une colonne au hasard,
    pluie[i].y = 2 + i * 4;     //   mais à des hauteurs différentes : 2, 6, 10
  }                             //   (pour qu'elles n'arrivent pas toutes ensemble).
  dessinerPanier();
  dessinerScore();
  ecran(1);                     // On rallume : le jeu commence.

  uint8_t attente = 0;          // Pour ralentir la pluie.

  while (true) {                // La boucle du jeu :
    image();

    // Le joueur : à chaque image (le panier est rapide).
    if (bouton(DROITE) && panier < 17) panier++;  // 17 + 2 = 19 : le bord droit.
    if (bouton(GAUCHE) && panier > 0) panier--;
    if (panier != ancienPanier) dessinerPanier(); // Ne redessine que s'il a bougé.

    // La pluie : un tour sur huit (elle est lente).
    attente++;
    if (attente < 8) continue;  // Pas encore 8 images : on saute la suite du tour.
    attente = 0;

    for (uint8_t i = 0; i < COMBIEN; i++) {   // Pour chaque goutte :
      texte(pluie[i].x, pluie[i].y, " ");     //   efface-la,
      pluie[i].tomber();                      //   fais-la descendre d'une ligne.

      if (attrape(i)) {                       //   Dans le panier ?
        score++;                              //     un point,
        lancer(i);                            //     elle repart d'en haut,
        dessinerScore();
      } else if (pluie[i].y >= SOL) {         //   Sinon, arrivée en bas, à côté ?
        vies--;                               //     une vie en moins,
        lancer(i);                            //     elle repart d'en haut,
        dessinerScore();
      }

      texte(pluie[i].x, pluie[i].y, "O");     //   Redessine-la.
    }

    if (vies == 0) break;       // Plus de vies : on SORT de la boucle du jeu.
  }

  // On arrive ici seulement après le break : la partie est finie.
  texte(6, 8, "PERDU!");
  texte(4, 10, "SCORE:");
  nombre(11, 10, score);

  while (true) {                // Une dernière boucle pour garder l'écran allumé.
    image();
  }
}

Trois O qui tombent, un panier |#| que GAUCHE et DROITE déplacent ; sans rien faire, « PERDU! » s’affiche au bout de quelques secondes.
