110.16. Devant, derrière : cache-toi du garde

Un petit jeu : traverse l’écran sans te faire voir. Le garde passe en haut ; derrière un arbre marqué DEVANT, il ne te voit pas.

1. Ce qu’il faut comprendre

Un petit jeu avec tout ce qu’on vient de voir. Ton héros part à gauche et doit atteindre la droite. Un garde fait les cent pas en haut de l’écran. S’il passe au-dessus de toi pendant que tu es à découvert, il te voit : retour au départ.

Les arbres sont des cachettes : leurs cases ont DEVANT. Derrière un arbre, ton héros disparaît, et le garde passe sans te voir.

Mais la console ne sait pas que tu es caché ! DEVANT ne change que le dessin. Pour le jeu, il faut le dire aussi dans le code : cache vaut 1 si le héros (8 pixels) est entièrement derrière un arbre (16 pixels). Le premier arbre va du pixel 40 au 55 : le héros y est caché pour x de 40 à 48 (48 + 8 = 56).

L’écart entre le garde et toi : ecart est la distance, toujours positive. Comme uint8_t ne connaît pas les nombres négatifs, on soustrait le plus petit du plus grand : g - x si le garde est à droite, x - g sinon. Moins de 12 pixels, et pas caché : vu !

Vu : le compteur vus augmente, le héros repart du pixel 8, et le garde repart de la droite (sinon il te reverrait aussitôt).

À toi : ajoute un troisième arbre, ou un second garde, plus rapide, en lutin 2.

📖 Les mots de cette leçon — si tu débutes

  • accolades { } — Elles entourent un bloc : les lignes qui vont ensemble (le corps d’une fonction, d’une boucle, d’un « if »). Chaque « { » a son « } ».
  • affectation (=) — « x = 5; » : la boîte x prend la valeur 5. Ce n’est pas une égalité : c’est un rangement.
  • argument — Une valeur donnée à une fonction quand on l’appelle, entre ses parenthèses : dans texte(5, 8, "SALUT"), 5, 8 et "SALUT" sont les arguments.
  • bloc — Un groupe de lignes entre accolades { }, qui s’exécutent ensemble.
  • booléen (vrai / faux) — Le résultat d’une condition : vrai (1) ou faux (0). « true » veut dire vrai, « false » faux.
  • boucle — Des instructions qui se répètent : « while » (tant que…) ou « for » (pour un compteur qui va de… à…).
  • boucle du jeu — « while (true) { image(); … } » : ce qui se répète 60 fois par seconde, sans fin, pendant tout le jeu.
  • bouton() — Une fonction de la console qui dit si un bouton de la manette est enfoncé : 1 oui, 0 non. Les boutons : A, B, HAUT, BAS, GAUCHE, DROITE, START, SELECT.
  • chaîne de caractères (texte) — Des lettres entre guillemets, "COMME CECI" : un texte pris tel quel. La police de la console n’a que des majuscules, sans accents.
  • commentaire (//) — Tout ce qui suit « // » jusqu’au bout de la ligne : une phrase pour l’humain, que la console ignore.
  • condition — Une question dont la réponse est vrai ou faux : « score > 10 », « bouton(A) ». On la teste avec « if » ou « while ».
  • coordonnées — Deux nombres qui disent où : la colonne (vers la droite) puis la ligne (vers le bas), à partir de (0, 0) en haut à gauche.
  • couleur, palette — En couleur (Game Boy Color), chaque dessin a quatre teintes ; une palette dit quelles couleurs. couleurFond() les règle pour le décor, couleurLutin() pour les lutins.
  • else (sinon) — Ce que l’on fait quand la condition du « if » est fausse.
  • for — Une boucle qui compte : « for (uint8_t i = 0; i < 5; i++) » fait 5 tours, i valant 0, 1, 2, 3 puis 4.
  • if (si) — Teste une condition : si elle est vraie, on fait le bloc qui suit.
  • image() — Attend l’image suivante. La console en montre 60 par seconde : c’est ce qui règle la vitesse d’un jeu.
  • #include — En haut du programme : « #include <texte> » demande la fonction texte() à la console ; « #include "fichier.cpp" » verse un de tes fichiers à cet endroit.
  • incrémenter (++) — « x++ » ou « x += 1 » : x augmente de 1. « x-- » : x diminue de 1.
  • instruction — Un ordre donné à la console, terminé par un point-virgule : « texte(1, 1, "OK"); ».
  • lutin (sprite) — Un dessin qui bouge au pixel près, par-dessus le décor : le héros, un ennemi. sprite() en place un de 8 × 8, sprite16() un de 16 × 16. La console en a 40.
  • main — « int main() { … } » : là où le programme commence. La console exécute d’abord la première ligne de main.
  • octet — Un nombre de 0 à 255 : la plus petite boîte de la mémoire. Une cartouche en a 32 768.
  • opérateurs de calcul — + plus, - moins, * fois, / divisé par (sans virgule : 7 / 2 donne 3), % le reste de la division (7 % 2 donne 1).
  • opérateurs de comparaison — == égal, != différent, < plus petit, > plus grand, <= plus petit ou égal, >= plus grand ou égal. Le résultat est vrai ou faux.
  • opérateurs logiques — && « et » (les deux doivent être vrais), || « ou » (un seul suffit), ! « pas ».
  • pixel — Un tout petit carré de couleur ; l’écran en a 160 de large et 144 de haut.
  • point-virgule (;) — Il termine une instruction, comme le point termine une phrase.
  • poser() — Met une tuile dans le décor, sur une case de la grille de 20 × 18 (32 × 32 en tout, avec la partie cachée).
  • texte() — Écrit des lettres à l’écran, sur la grille de 20 colonnes et 18 lignes : texte(colonne, ligne, "MOT").
  • Tuile — Un dessin de 8 × 8 pixels, écrit rangée par rangée avec des signes (. - + #). Le décor en est fait.
  • uint8_t — Le genre de nombre de cette console : un entier de 0 à 255 (un octet). Au-delà, il repart à 0.
  • variable — Une boîte avec un nom, dans la mémoire, qui retient un nombre qu’on peut lire et changer.
  • while (tant que) — Répète un bloc tant qu’une condition est vraie.

// CE PROGRAMME (Game Boy Color) : un petit jeu de cache-cache.
//   GAUCHE / DROITE : ton héros (en bas) doit atteindre la droite de l'écran.
//   Le GARDE fait les cent pas en haut. S'il passe au-dessus de toi pendant que
//   tu es à découvert : VU, retour au départ.
//   Derrière un ARBRE (cases DEVANT), tu es caché : il ne te voit pas.
//
// Ce qui est nouveau : DEVANT ne change que le DESSIN. Pour le jeu, on calcule
// aussi, dans le code, si le héros est caché (la variable cache).

int main() {                              // Le jeu commence ici.
  couleurFond(0, 0, 20, 28, 31);          // palette 0 : le ciel et le texte
  couleurFond(0, 3,  2,  4, 12);
  couleurFond(2, 1,  8, 18,  4);          // palette 2 : l'arbre, vert,
  couleurFond(2, 2,  4, 26,  6);          //   vert vif,
  couleurFond(2, 3,  0, 10,  2);          //   vert sombre.
  couleurLutin(0, 1, 28, 31, 31);         // toi : bleu pâle,
  couleurLutin(0, 2,  4, 12, 31);         //   bleu,
  couleurLutin(0, 3,  0,  0, 10);         //   bleu nuit.
  couleurLutin(1, 1, 31, 31, 31);         // le garde : blanc,
  couleurLutin(1, 2, 31,  4,  2);         //   rouge,
  couleurLutin(1, 3, 10,  0,  0);         //   rouge sombre.

  ecran(0);                               // Dessin écran éteint.
  texte(1, 1, "VUS");
  // Deux arbres de 2 × 2 cases, lignes 8 et 9 : colonnes 5-6, puis 13-14.
  for (uint8_t l = 8; l < 10; l++) {
    poser(5, l, ARBRE);  teindre(5, l, 2 | DEVANT);
    poser(6, l, ARBRE);  teindre(6, l, 2 | DEVANT);
    poser(13, l, ARBRE); teindre(13, l, 2 | DEVANT);
    poser(14, l, ARBRE); teindre(14, l, 2 | DEVANT);
  }
  ecran(1);                               // On rallume.
  nombre(5, 1, vus);

  while (true) {                          // La boucle du jeu :
    image();

    // Toi : GAUCHE / DROITE.
    if (bouton(DROITE) && x < 152) x++;
    if (bouton(GAUCHE) && x > 8) x--;

    // Le garde : un pixel toutes les 2 images, et demi-tour aux bords.
    if (images() % 2 == 0) {
      if (sens == 0) {
        g--;
        if (g == 0) sens = 1;             // au bord gauche : il repart à droite
      } else {
        g++;
        if (g == 152) sens = 0;           // au bord droit : il repart à gauche
      }
    }

    // Caché ? Tout entier derrière un arbre (le héros fait 8 pixels, l'arbre 16).
    uint8_t cache = 0;
    if (x >= 40 && x <= 48) cache = 1;    // arbre 1 : pixels 40 à 55
    if (x >= 104 && x <= 112) cache = 1;  // arbre 2 : pixels 104 à 119

    // L'écart entre le garde et toi, toujours positif.
    uint8_t ecart = 0;
    if (g > x) {
      ecart = g - x;                      // le garde est à droite
    } else {
      ecart = x - g;                      // le garde est à gauche (ou pile au-dessus)
    }

    if (ecart < 12 && cache == 0) {       // Tout près, et à découvert : VU !
      vus++;
      nombre(5, 1, vus);
      x = 8;                              // retour au départ,
      g = 150;                            // et le garde repart de la droite.
      sens = 0;
    }

    if (x >= 150) texte(8, 1, "GAGNE");   // Arrivé à droite !

    sprite(0, x, 68, HEROS);              // Toi, en bas, à la hauteur des arbres.
    teindreLutin(0, 0);
    sprite(1, g, 40, GARDE);              // Le garde, en haut.
    teindreLutin(1, 1);
  }
}

Deux arbres verts, ton héros bleu à gauche, un garde rouge qui va et vient en haut. Derrière un arbre, ton héros disparaît et le garde ne le voit pas ; à découvert, il te renvoie au départ.
