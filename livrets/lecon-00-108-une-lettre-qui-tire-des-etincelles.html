0.108. Une lettre qui tire — des étincelles

La rafale du 0.105.1 : chaque tir est un point, et il casse un seul X, celui qu’il touche en face. Au choc, un petit éclat jaillit : six étincelles de 2 × 2 pixels, jaunes et orange, qui scintillent un instant puis disparaissent.

1. Ce qu’il faut comprendre

On reprend la rafale du 0.105.1, et on lui ajoute un effet. Le tir est un point « . » ; il casse un seul X, celui qu’il touche en face, et disparaît. Au moment du choc, un petit éclat jaillit du trou : six étincelles jaunes et orange, qui scintillent un instant, puis s’éteignent.

Ce qui est nouveau ici (1) : une étincelle est un lutin. Une lettre ne bouge que case par case : 8 pixels d’un coup. Un lutin (le 0.70) se pose au pixel près, avec sprite(numero, x, y, dessin). Les six étincelles sont les lutins 0 à 5 ; leur place se compte en pixels : px[i], py[i]. La case (c, l) commence au pixel (c × 8, l × 8).

Ce qui est nouveau ici (2) : un dessin à nous, Tuile ETINCELLE. Huit lignes de huit chiffres : un chiffre par pixel. 0 est transparent (on voit le décor derrière) ; 1 et 2 sont deux couleurs. Seuls quatre pixels, au milieu, sont allumés : 2 × 2, une étincelle.

Ce qui est nouveau ici (3) : les couleurs. couleurLutin(palette, teinte, rouge, vert, bleu) règle une teinte d’une palette de lutins, avec trois nombres de 0 à 31. La palette 0 met le jaune (31, 31, 6) en 1 et l’orange (31, 16, 0) en 2 ; la palette 1 les échange. teindreLutin(i, palette) choisit la palette du lutin i. Le programme s’en sert : la console passe toute seule en mode couleur.

Ce qui est nouveau ici (4) : eclat(c, l). Quand un tir casse le X en (nx, ny), on appelle eclat(nx, ny) : les six étincelles sont posées au centre de cette case, et chacune reçoit une vie de 6 à 11 images (6 + hasard() % 6). Elles ne s’éteignent pas toutes ensemble : c’est ce qui fait « étincelles ».

etinceler(), à chaque image : chaque étincelle encore vivante perd une image de vie, avance d’un pixel dans sa direction (PDX[i], PDY[i], gravées dans la cartouche : 255 veut dire -1, le 0.100), est redessinée, et scintille : teindreLutin(i, ((images() + i) / 2) % 2) la fait passer du jaune à l’orange toutes les 2 images. À 0, cacher(i) la fait disparaître.

Un seul X, celui d’en face : rien ne change dans le pas du tir du 0.105.1. Son arrivée est un X : effacer(nx, ny, 1) efface cette case-là, le tir disparaît, et l’éclat part de là. Les X au-dessus et au-dessous ne sont pas touchés.

Déroulons : A en (2, 8), bouton A. Le point va de (3, 8) à (11, 8). Pas suivant : l’arrivée (12, 8) est un X. Il est effacé, le tir disparaît, et eclat(12, 8) pose les six étincelles au pixel (96, 64). Une image plus tard, elles s’écartent d’un pixel : deux en haut, deux en bas, deux de chaque côté. Dix images plus tard, il n’en reste plus.

Essaie : change les couleurs (du bleu et du blanc pour de la glace : 10, 20, 31 et 31, 31, 31). Ou un éclat plus long : 12 + hasard() % 8.

📖 Les mots de cette leçon — si tu débutes

  • accolades { } — Elles entourent un bloc : les lignes qui vont ensemble (le corps d’une fonction, d’une boucle, d’un « if »). Chaque « { » a son « } ».
  • affectation (=) — « x = 5; » : la boîte x prend la valeur 5. Ce n’est pas une égalité : c’est un rangement.
  • argument — Une valeur donnée à une fonction quand on l’appelle, entre ses parenthèses : dans texte(5, 8, "SALUT"), 5, 8 et "SALUT" sont les arguments.
  • bloc — Un groupe de lignes entre accolades { }, qui s’exécutent ensemble.
  • booléen (vrai / faux) — Le résultat d’une condition : vrai (1) ou faux (0). « true » veut dire vrai, « false » faux.
  • boucle — Des instructions qui se répètent : « while » (tant que…) ou « for » (pour un compteur qui va de… à…).
  • boucle du jeu — « while (true) { image(); … } » : ce qui se répète 60 fois par seconde, sans fin, pendant tout le jeu.
  • bouton() — Une fonction de la console qui dit si un bouton de la manette est enfoncé : 1 oui, 0 non. Les boutons : A, B, HAUT, BAS, GAUCHE, DROITE, START, SELECT.
  • chaîne de caractères (texte) — Des lettres entre guillemets, "COMME CECI" : un texte pris tel quel. La police de la console n’a que des majuscules, sans accents.
  • commentaire (//) — Tout ce qui suit « // » jusqu’au bout de la ligne : une phrase pour l’humain, que la console ignore.
  • condition — Une question dont la réponse est vrai ou faux : « score > 10 », « bouton(A) ». On la teste avec « if » ou « while ».
  • constante (const) — Une valeur qui a un nom et ne change jamais : « const uint8_t VIES = 3; ».
  • coordonnées — Deux nombres qui disent où : la colonne (vers la droite) puis la ligne (vers le bas), à partir de (0, 0) en haut à gauche.
  • couleur, palette — En couleur (Game Boy Color), chaque dessin a quatre teintes ; une palette dit quelles couleurs. couleurFond() les règle pour le décor, couleurLutin() pour les lutins.
  • else (sinon) — Ce que l’on fait quand la condition du « if » est fausse.
  • fonction — Un groupe d’instructions qui a un nom, qu’on lance en écrivant son nom et des parenthèses. Celles de la console (texte, poser…) sont toutes prêtes ; on peut écrire les siennes.
  • for — Une boucle qui compte : « for (uint8_t i = 0; i < 5; i++) » fait 5 tours, i valant 0, 1, 2, 3 puis 4.
  • hasard() — Une fonction de la console qui rend un nombre au hasard, de 0 à 255.
  • if (si) — Teste une condition : si elle est vraie, on fait le bloc qui suit.
  • image() — Attend l’image suivante. La console en montre 60 par seconde : c’est ce qui règle la vitesse d’un jeu.
  • #include — En haut du programme : « #include <texte> » demande la fonction texte() à la console ; « #include "fichier.cpp" » verse un de tes fichiers à cet endroit.
  • incrémenter (++) — « x++ » ou « x += 1 » : x augmente de 1. « x-- » : x diminue de 1.
  • indice — Le numéro d’une case dans un tableau, entre crochets : cases[3] est la quatrième case (on compte à partir de 0).
  • instruction — Un ordre donné à la console, terminé par un point-virgule : « texte(1, 1, "OK"); ».
  • lutin (sprite) — Un dessin qui bouge au pixel près, par-dessus le décor : le héros, un ennemi. sprite() en place un de 8 × 8, sprite16() un de 16 × 16. La console en a 40.
  • main — « int main() { … } » : là où le programme commence. La console exécute d’abord la première ligne de main.
  • octet — Un nombre de 0 à 255 : la plus petite boîte de la mémoire. Une cartouche en a 32 768.
  • opérateurs de calcul — + plus, - moins, * fois, / divisé par (sans virgule : 7 / 2 donne 3), % le reste de la division (7 % 2 donne 1).
  • opérateurs de comparaison — == égal, != différent, < plus petit, > plus grand, <= plus petit ou égal, >= plus grand ou égal. Le résultat est vrai ou faux.
  • opérateurs logiques — && « et » (les deux doivent être vrais), || « ou » (un seul suffit), ! « pas ».
  • paramètre — Dans la définition d’une fonction, la boîte qui reçoit une valeur donnée à l’appel : dans « void f(uint8_t x) », x est un paramètre.
  • pixel — Un tout petit carré de couleur ; l’écran en a 160 de large et 144 de haut.
  • point-virgule (;) — Il termine une instruction, comme le point termine une phrase.
  • poser() — Met une tuile dans le décor, sur une case de la grille de 20 × 18 (32 × 32 en tout, avec la partie cachée).
  • tableau — Une rangée de boîtes sous un même nom : « uint8_t cases[10]; » donne cases[0] à cases[9].
  • texte() — Écrit des lettres à l’écran, sur la grille de 20 colonnes et 18 lignes : texte(colonne, ligne, "MOT").
  • Tuile — Un dessin de 8 × 8 pixels, écrit rangée par rangée avec des signes (. - + #). Le décor en est fait.
  • uint8_t — Le genre de nombre de cette console : un entier de 0 à 255 (un octet). Au-delà, il repart à 0.
  • variable — Une boîte avec un nom, dans la mémoire, qui retient un nombre qu’on peut lire et changer.
  • void — Devant une fonction : elle ne rend rien, elle agit seulement.
  • while (tant que) — Répète un bloc tant qu’une condition est vraie.

void eclat(uint8_t c, uint8_t l) {
  for (uint8_t i = 0; i < 6; i++) {
    px[i] = c * 8;
    py[i] = l * 8;
    vie[i] = 6 + hasard() % 6;       // de 6 à 11 images : un instant
  }
}

21. une fonction — etinceler()

void etinceler() {
  for (uint8_t i = 0; i < 6; i++) {
    if (vie[i] > 0) {
      vie[i] = vie[i] - 1;
      if (vie[i] == 0) {
        cacher(i);                   // plus de vie : le lutin i disparaît
      } else {
        px[i] = px[i] + PDX[i];      // elle file dans SA direction…
        py[i] = py[i] + PDY[i];
        sprite(i, px[i], py[i], ETINCELLE);
        // …et scintille : toutes les 2 images, elle passe d'une palette à
        // l'autre (0 : jaune au milieu, 1 : orange). Après sprite(), qui
        // remet la palette à 0.
        teindreLutin(i, ((images() + i) / 2) % 2);
      }
    }
  }
}

              tdy[i] = dy;
              texte(tx[i], ty[i], ".");
              lance = 1;
            }
          }
        }
      }
    }

    // ---- chaque tir avance, et regarde sa case d'arrivée (le 0.105) ----
    if (chaque(100)) {
      for (uint8_t i = 0; i < 3; i++) {
        if (vole[i] == 1) {
          nx = tx[i] + tdx[i];
          ny = ty[i] + tdy[i];
          effacer(tx[i], ty[i], 1);
          if (nx >= 20 || ny >= 17) {
            vole[i] = 0;             // 1. hors de l'écran
          } else if (lire(nx, ny) == ALPHABET[23]) {
            effacer(nx, ny, 1);      // 2. un X : le tir casse CE X-là, et lui seul…
            vole[i] = 0;             //    …disparaît…
            eclat(nx, ny);           //    …et NOUVEAU : un éclat jaillit du choc
          } else if (lire(nx, ny) != 0) {
            vole[i] = 0;             // 3. un autre tir : il s'écrase
          } else {
            tx[i] = nx;              // 4. une case vide : il y va
            ty[i] = ny;
            texte(tx[i], ty[i], ".");
          }
        }
      }
    }

    // ---- NOUVEAU : les étincelles vivent, une image après l'autre ----
    etinceler();
  }
}
