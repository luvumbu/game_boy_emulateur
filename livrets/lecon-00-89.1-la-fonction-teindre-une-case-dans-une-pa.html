0.89.1. La fonction teindre() — une case dans une palette

#include <teindre> : teindre(colonne, ligne, palette) met une case du fond dans une autre palette (Game Boy Color).

1. Ce qu’il faut comprendre

Ce qu’elle fait : toute case est dans la palette 0, jusqu’à ce qu’on la teigne. teindre(colonne, ligne, palette) met cette case dans une autre palette : la même tuile peut avoir des couleurs différentes d’une case à l’autre.

La ligne à écrire : #include <teindre>.

Ses arguments : la colonne, la ligne, la palette (0 à 7). palette | DEVANT fait passer la case devant les personnages.

Ce qu’elle coûte : environ 100 octets la première fois.

Essaie : teins aussi la case (7, 8) : deux lettres en bleu.

On retrouve teindre dans 15 leçons

0.89.2, 0.92, 0.92.1, 0.92.2, 36, 37, 102, 103, 105, 106, 110.6, 110.7, 110.9, 110.13, 152

1. ce que le programme raconte de lui-même

// ---- #include <teindre> : une case dans une palette ----
// BLEU s'écrit ; seule sa première case passe dans la palette 2, bleue.

#include <couleurFond>
#include <texte>
#include <teindre>     // teindre() : la palette d'une case

2. le point d’entrée : c’est ici que la console arrive

int main() {
  couleurFond(2, 3, 0, 0, 31);   // palette 2, teinte 3 (les lettres) : bleu
  texte(6, 8, "BLEU");
  teindre(6, 8, 2);              // la case du B dans la palette 2

  while (true) {
    image();
  }
}

3. Ce qui se passe, étape par étape

La cartouche a été compilée et exécutée pour de bon ; voici son écran aux instants qui comptent. Une image identique à la précédente n’est pas montrée — un programme qui ne bouge pas n’a qu’une seule image, et c’est la vérité sur ce programme.

BLEU, dont seul le B est bleu.

5. Ce que la console répond

Ces contrôles ne sont pas décoratifs : ce sont ceux que verifier-tuto.mjs exige de cette leçon. Ils viennent d’être joués, et voici ce qu’ils ont mesuré.

  • la case du B est dans la palette 2 (2)
  • la case du L reste dans la palette 0
