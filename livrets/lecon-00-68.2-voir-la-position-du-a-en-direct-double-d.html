0.68.2. Voir la position du A en direct — doublé, deux positions

Les deux positions en direct : le A à gauche, le B à droite de la ligne 17.

1. Ce qu’il faut comprendre

C’est le 0.68 et le 0.68.1 réunis : deux lettres, quatre nombres.

Les fonctions de cette leçon — et le tuto de chacune

  • #include <effacer> → 0.16.3. La fonction effacer() — effacer des cases
  • #include <bouton> → 0.65.5. La fonction bouton() — lire la manette
  • #include <nombre> → 0.8.3. La fonction nombre() — écrire un nombre
  • #include <poser> → 0.1.3. La fonction poser() — poser une tuile
  • #include <ALPHABET> → 0.1.4. ALPHABET — les lettres de la police

2. le point d’entrée : c’est ici que la console arrive

int main() {
  while (true) {
    image();
    if (attente > 0) attente--;
    if (attente == 0) {
      effacer(x, y, 1);
      effacer(xb, yb, 1);
      if (bouton(DROITE)) { if (x < 19) x++; if (xb < 19) xb++; attente = 8; }
      if (bouton(GAUCHE)) { if (x > 0) x--; if (xb > 0) xb--; attente = 8; }
      if (bouton(BAS))    { if (y < 17) y++; if (yb < 17) yb++; attente = 8; }
      if (bouton(HAUT))   { if (y > 0) y--; if (yb > 0) yb--; attente = 8; }
    }
    nombre(0, 17, x);
    nombre(4, 17, y);
    nombre(10, 17, xb);
    nombre(14, 17, yb);
    poser(x, y, ALPHABET[0]);
    poser(xb, yb, ALPHABET[1]);
  }
}
