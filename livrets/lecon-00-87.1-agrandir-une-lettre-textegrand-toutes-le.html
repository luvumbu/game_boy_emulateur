0.87.1. Agrandir une lettre : texteGrand — toutes les tailles

Le même A, aux tailles 1, 2, 3 et 4, côte à côte : un seul nombre change d’une ligne à l’autre.

1. Ce qu’il faut comprendre

Quatre lignes, un seul nombre qui change : la taille, 1, 2, 3, puis 4. On voit le A grandir.

Tu choisis la taille, la console s’adapte : aucune taille n’est dessinée à l’avance. Chaque texteGrand fait calculer les tuiles de SA taille.

La place : taille 1, 1 case ; taille 2, 2 × 2 ; taille 3, 3 × 3 ; taille 4, 4 × 4. Les colonnes de départ (0, 2, 5, 9) laissent juste la place à chacun.

Les fonctions de cette leçon — et le tuto de chacune

  • #include <texteGrand> → 0.86.3. La fonction texteGrand() — un texte agrandi

2. Le programme, morceau par morceau

Le programme entier de la leçon, découpé comme l’œil le lit. Il fait 1753 octets de cartouche.

1. ce que le programme raconte de lui-même

#include <texteGrand>   // écrit un texte agrandi, de 1 à 20 fois

2. le point d’entrée : c’est ici que la console arrive

int main() {
  texteGrand(0, 0, "A", 1);     // taille 1 : 1 case, comme une lettre normale
  texteGrand(2, 0, "A", 2);     // taille 2 : 2 × 2 cases
  texteGrand(5, 0, "A", 3);     // taille 3 : 3 × 3 cases
  texteGrand(9, 0, "A", 4);     // taille 4 : 4 × 4 cases

  while (true) {
    image();
  }
}

3. Ce qui se passe, étape par étape

La cartouche a été compilée et exécutée pour de bon ; voici son écran aux instants qui comptent. Une image identique à la précédente n’est pas montrée — un programme qui ne bouge pas n’a qu’une seule image, et c’est la vérité sur ce programme.

4. Ce qu’on doit voir

Quatre A côte à côte, de plus en plus grands : tailles 1, 2, 3 et 4.

5. Ce que la console répond

Ces contrôles ne sont pas décoratifs : ce sont ceux que verifier-tuto.mjs exige de cette leçon. Ils viennent d’être joués, et voici ce qu’ils ont mesuré.

  • taille 1 : une case
  • taille 4 : dans ses 4 × 4 cases
  • chacun plus grand que le précédent
