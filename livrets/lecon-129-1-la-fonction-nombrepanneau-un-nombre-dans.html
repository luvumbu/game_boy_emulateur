129.1. La fonction nombrePanneau() — un nombre dans le panneau

#include <nombrePanneau> : nombrePanneau(colonne, ligne, valeur) écrit un nombre dans le panneau, comme nombre() sur le fond.

1. Ce qu’il faut comprendre

Ce qu’elle fait : nombrePanneau(colonne, ligne, valeur) écrit un nombre calculé dans le panneau : le score qui reste en place quand le décor défile.

La ligne à écrire : #include <nombrePanneau>.

Ses arguments : comme nombre(), avec le nombre de chiffres en quatrième, facultatif.

Ce qu’elle coûte : environ 320 octets la première fois.

Essaie : fais monter le score toutes les secondes, et réécris-le.

On retrouve nombrePanneau dans 1 leçon

130

2. Le programme, morceau par morceau

Le programme entier de la leçon, découpé comme l’œil le lit. Il fait 529 octets de cartouche.

Ce que le compilateur y a gravé, nommé — chaque morceau, sa taille, qui l’a demandé — et ce qu’il a laissé, parce que rien ne l’appelle :

Gravé dans la cartouche :
  démarrage        53 o  ← la console, à l’allumage  — la mise en route de la console
  main()           43 o  ← démarrage  — ta fonction
  VBlank            8 o  ← la console, à chaque image  — compte les images, 60 fois par seconde
  AttendreImage    28 o  ← image()  — attend l’image suivante
  AttendreVBlank   16 o  ← démarrage  — attend que l’écran soit libre
  AttendreAcces    12 o  ← EcrireTexte, EcrireNombre  — attend de pouvoir écrire une case
  EcrireTexte      10 o  ← textePanneau()  — écrit un texte, lettre par lettre
  EcrireNombre     33 o  ← nombrePanneau()  — écrit un nombre en chiffres
  CopierTuiles     67 o  ← démarrage  — copie les lettres et les dessins en mémoire vidéo
  EffacerCarte     14 o  ← démarrage  — vide les deux cartes de l’écran
  Tuiles          240 o  ← CopierTuiles  — 15 lettres sur 43
  "SCORE"           5 o  ← textePanneau()  — un texte gravé

1. ce que le programme raconte de lui-même

#include <textePanneau>
#include <nombrePanneau>   // nombrePanneau() : une valeur, dans le panneau
#include <panneau>

2. une variable — score

uint8_t score = 120;

3. le point d’entrée : c’est ici que la console arrive

int main() {
  textePanneau(1, 0, "SCORE");
  nombrePanneau(7, 0, score);   // 120, juste après SCORE
  panneau(0, 128);

  while (true) {
    image();
  }
}
