0.1.4. ALPHABET — les lettres de la police

#include <ALPHABET> : ALPHABET[0] est le A, ALPHABET[25] le Z — le numéro de la lettre, pour poser(), sprite()…

1. Ce qu’il faut comprendre

Ce que c’est : ALPHABET range les lettres de la police dans l’ordre : ALPHABET[0] est le A, ALPHABET[1] le B… ALPHABET[25] le Z. Ce n’est pas un tableau en mémoire : ALPHABET[i] se calcule « 1 + i », et ne coûte rien de plus.

La ligne à écrire : #include <ALPHABET>.

Ce qu’il coûte : une lettre écrite en clair (ALPHABET[7]) grave 16 octets : son dessin, et rien d’autre. Une lettre calculée (ALPHABET[i]) peut être n’importe laquelle : la police entière part dans la cartouche, 704 octets.

Essaie : remplace ALPHABET[7] par ALPHABET[i] dans une boucle : regarde la ROM grossir de 700 octets.

2. Le programme, morceau par morceau

Le programme entier de la leçon, découpé comme l’œil le lit. Il fait 197 octets de cartouche.

Ce que le compilateur y a gravé, nommé — chaque morceau, sa taille, qui l’a demandé — et ce qu’il a laissé, parce que rien ne l’appelle :

Gravé dans la cartouche :
  démarrage        49 o  ← la console, à l’allumage  — la mise en route de la console
  main()           19 o  ← démarrage  — ta fonction
  VBlank            8 o  ← la console, à chaque image  — compte les images, 60 fois par seconde
  AttendreImage    28 o  ← image()  — attend l’image suivante
  AttendreVBlank   16 o  ← démarrage  — attend que l’écran soit libre
  CopierTuiles     31 o  ← démarrage  — copie les lettres et les dessins en mémoire vidéo
  EffacerCarte     14 o  ← démarrage  — vide les deux cartes de l’écran
  Tuiles           32 o  ← CopierTuiles  — 2 lettres sur 43
Lettres gravées : HI
Pas gravé (jamais appelé) : AvancerAirs, AttendreAcces, AttendreFinVBlank, AdresseCase, EffacerCases, EcrireTexte, EcrireNombre, Diviser, Reste, Multiplier, DecalerGauche, DecalerDroite, RangerLutins, InstallerTransfert, Hasard, EffacerFond, EffacerPanneau, LireManette, DonneesTransfert, Notes

1. ce que le programme raconte de lui-même

// ---- #include <ALPHABET> : les lettres de la police ----
// ALPHABET[0] = A, ALPHABET[1] = B, … ALPHABET[25] = Z.

#include <ALPHABET>   // ALPHABET : le numéro de chaque lettre
#include <poser>

2. le point d’entrée : c’est ici que la console arrive

int main() {
  poser(8, 8, ALPHABET[7]);    // la lettre numéro 7 : H (A=0, B=1, … H=7)
  poser(9, 8, ALPHABET[8]);    // la lettre numéro 8 : I

  while (true) {
    image();
  }
}

3. Ce qui se passe, étape par étape

La cartouche a été compilée et exécutée pour de bon ; voici son écran aux instants qui comptent. Une image identique à la précédente n’est pas montrée — un programme qui ne bouge pas n’a qu’une seule image, et c’est la vérité sur ce programme.

HI au milieu de l’écran.
