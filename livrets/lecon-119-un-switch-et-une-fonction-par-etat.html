119. Un switch, et une fonction par état

La boucle ne fait plus qu’aiguiller : chaque état a sa fonction, et une seule fonction change d’état.

1. Ce qu’il faut comprendre

Avec un vrai jeu dans l’état JEU, le if … else if de la leçon d’avant grossirait jusqu’à ne plus tenir sur l’écran. On range donc chaque état dans sa fonction : titre(), jeu(), perdu().

Ce qui est nouveau ici : le switch sur l’état, et changer(). Le switch (chapitre 2) aiguille vers la fonction de l’état en cours ; main ne fait plus rien d’autre. Et une seule fonction, changer(nouvel), a le droit de changer d’état : elle efface l’écran, dessine le nouveau, et prépare ses variables.

Pourquoi une seule ? Parce que chaque état a quelque chose à faire en entrant : la partie remet le score à 0 et lance le chrono ; l’écran de fin affiche le score. Si trois endroits du programme changeaient etat à la main, on oublierait une fois sur deux de remettre le score à zéro.

changer(Etat nouvel) prend un argument de type Etat : on ne peut lui passer que TITRE, JEU ou PERDU. Même le compilateur lit le programme plus facilement.

La partie est un petit jeu : appuyer sur A le plus de fois possible en cinq secondes. Le front de A (un appui, un point), le compte à rebours du chapitre 11, et quand il tombe à 0 : changer(PERDU).

Le changement d’écran se fait écran éteint : ecran(0), on efface et on écrit, ecran(1). Rien ne se voit à moitié dessiné.

À toi : ajoute l’état PAUSE avec sa fonction pause(), et vérifie que le temps ne s’écoule pas pendant la pause.

📖 Les mots de cette leçon — si tu débutes

  • accolades { } — Elles entourent un bloc : les lignes qui vont ensemble (le corps d’une fonction, d’une boucle, d’un « if »). Chaque « { » a son « } ».
  • affectation (=) — « x = 5; » : la boîte x prend la valeur 5. Ce n’est pas une égalité : c’est un rangement.
  • argument — Une valeur donnée à une fonction quand on l’appelle, entre ses parenthèses : dans texte(5, 8, "SALUT"), 5, 8 et "SALUT" sont les arguments.
  • bloc — Un groupe de lignes entre accolades { }, qui s’exécutent ensemble.
  • booléen (vrai / faux) — Le résultat d’une condition : vrai (1) ou faux (0). « true » veut dire vrai, « false » faux.
  • boucle — Des instructions qui se répètent : « while » (tant que…) ou « for » (pour un compteur qui va de… à…).
  • boucle du jeu — « while (true) { image(); … } » : ce qui se répète 60 fois par seconde, sans fin, pendant tout le jeu.
  • bouton() — Une fonction de la console qui dit si un bouton de la manette est enfoncé : 1 oui, 0 non. Les boutons : A, B, HAUT, BAS, GAUCHE, DROITE, START, SELECT.
  • break — Sort tout de suite de la boucle (ou du « switch ») où l’on est.
  • chaîne de caractères (texte) — Des lettres entre guillemets, "COMME CECI" : un texte pris tel quel. La police de la console n’a que des majuscules, sans accents.
  • commentaire (//) — Tout ce qui suit « // » jusqu’au bout de la ligne : une phrase pour l’humain, que la console ignore.
  • condition — Une question dont la réponse est vrai ou faux : « score > 10 », « bouton(A) ». On la teste avec « if » ou « while ».
  • coordonnées — Deux nombres qui disent où : la colonne (vers la droite) puis la ligne (vers le bas), à partir de (0, 0) en haut à gauche.
  • fonction — Un groupe d’instructions qui a un nom, qu’on lance en écrivant son nom et des parenthèses. Celles de la console (texte, poser…) sont toutes prêtes ; on peut écrire les siennes.
  • for — Une boucle qui compte : « for (uint8_t i = 0; i < 5; i++) » fait 5 tours, i valant 0, 1, 2, 3 puis 4.
  • if (si) — Teste une condition : si elle est vraie, on fait le bloc qui suit.
  • image() — Attend l’image suivante. La console en montre 60 par seconde : c’est ce qui règle la vitesse d’un jeu.
  • #include — En haut du programme : « #include <texte> » demande la fonction texte() à la console ; « #include "fichier.cpp" » verse un de tes fichiers à cet endroit.
  • incrémenter (++) — « x++ » ou « x += 1 » : x augmente de 1. « x-- » : x diminue de 1.
  • instruction — Un ordre donné à la console, terminé par un point-virgule : « texte(1, 1, "OK"); ».
  • main — « int main() { … } » : là où le programme commence. La console exécute d’abord la première ligne de main.
  • octet — Un nombre de 0 à 255 : la plus petite boîte de la mémoire. Une cartouche en a 32 768.
  • opérateurs de calcul — + plus, - moins, * fois, / divisé par (sans virgule : 7 / 2 donne 3), % le reste de la division (7 % 2 donne 1).
  • opérateurs de comparaison — == égal, != différent, < plus petit, > plus grand, <= plus petit ou égal, >= plus grand ou égal. Le résultat est vrai ou faux.
  • opérateurs logiques — && « et » (les deux doivent être vrais), || « ou » (un seul suffit), ! « pas ».
  • point-virgule (;) — Il termine une instruction, comme le point termine une phrase.
  • return — Termine la fonction et rend une valeur à celui qui l’a appelée.
  • switch / case — Choisir entre plusieurs cas selon la valeur d’une variable, au lieu d’une suite de « if ».
  • texte() — Écrit des lettres à l’écran, sur la grille de 20 colonnes et 18 lignes : texte(colonne, ligne, "MOT").
  • uint8_t — Le genre de nombre de cette console : un entier de 0 à 255 (un octet). Au-delà, il repart à 0.
  • variable — Une boîte avec un nom, dans la mémoire, qui retient un nombre qu’on peut lire et changer.
  • void — Devant une fonction : elle ne rend rien, elle agit seulement.
  • while (tant que) — Répète un bloc tant qu’une condition est vraie.

1. ce que le programme raconte de lui-même

// CE PROGRAMME : « LE JEU DU A ». Au titre, START lance la partie.
// Pendant 5 secondes, chaque appui sur A donne un point. Puis FINI!,
// et START ramène au titre.
//
// Ce qui est nouveau : une fonction par état, et UNE SEULE fonction, changer(),
// qui passe d'un état à l'autre. La boucle du jeu ne fait plus qu'aiguiller :
// switch (etat) appelle titre(), jeu() ou perdu().

#include <bouton>   // lit un bouton de la manette
#include <ecran>    // éteint ou rallume l’écran
#include <texte>    // écrit un texte à l’écran
#include <nombre>   // écrit un nombre en chiffres

2. des constantes nommées — Etat

enum Etat { TITRE, JEU, PERDU };   // Les trois écrans : TITRE = 0, JEU = 1, PERDU = 2.

3. une variable — etat

Etat etat = TITRE;       // L'écran actuel.

4. une variable — score

uint8_t score = 0;       // Les points de la partie.

5. une variable — reste

uint8_t reste = 5;       // les secondes de la partie

6. une variable — top

uint8_t top = 0;         // images() au début de la seconde en cours

7. une variable — avantStart

uint8_t avantStart = 0;  // START à l'image d'avant

8. une variable — avantA

uint8_t avantA = 0;      // A à l'image d'avant

// 1 à la première image d'un appui sur START, 0 sinon (le front).

9. une fonction — appuiStart()

uint8_t appuiStart() {
  uint8_t s = bouton(START);         // START maintenant ?
  uint8_t front = s && !avantStart;  // maintenant ET pas avant
  avantStart = s;                    // on retient pour la prochaine fois
  return front;
}

// LA SEULE fonction qui change d'état : elle dessine le nouvel écran.

10. une fonction — changer()

void changer(Etat nouvel) {
  etat = nouvel;                     // On passe au nouvel état.
  ecran(0);                          // Écran éteint pendant qu'on redessine.
  for (uint8_t l = 4; l < 14; l++) texte(0, l, "                    ");  // efface lignes 4 à 13

  switch (etat) {                    // Selon le nouvel état :
    case TITRE:                      // --- le titre
      texte(5, 6, "LE JEU DU A");
      texte(4, 10, "START: JOUER");
      break;                         // « break » : fin de ce cas.
    case JEU:                        // --- la partie
      score = 0;               // en entrant dans la partie : tout repart de zéro
      reste = 5;
      top = images();          // le chrono démarre maintenant
      texte(3, 6, "APPUIE SUR A!");
      texte(3, 9, "POINTS");
      nombre(10, 9, score);
      texte(3, 10, "TEMPS");
      nombre(10, 10, reste, 1);
      break;
    case PERDU:                      // --- la fin
      texte(7, 6, "FINI!");
      texte(3, 9, "POINTS");
      nombre(10, 9, score);
      texte(4, 12, "START: TITRE");
      break;
  }
  ecran(1);                          // On rallume.
}

11. une fonction — titre()

void titre() {                       // Ce que fait le jeu, à chaque image, au titre :
  if (appuiStart()) changer(JEU);    //   START → la partie.
}

12. une fonction — jeu()

void jeu() {                         // À chaque image, pendant la partie :
  uint8_t a = bouton(A);
  if (a && !avantA) {          // un appui, un point (le front de A)
    score++;
    nombre(10, 9, score);
  }
  avantA = a;

  uint8_t ecoule = images() - top;   // images depuis le début de la seconde
  if (ecoule >= 60) {          // une seconde de moins
    top = top + 60;
    reste--;
    nombre(10, 10, reste, 1);
    if (reste == 0) changer(PERDU);  // le temps est écoulé → fin
  }
}

13. une fonction — perdu()

void perdu() {                       // À chaque image, à l'écran de fin :
  if (appuiStart()) changer(TITRE);  //   START → retour au titre.
}

14. le point d’entrée : c’est ici que la console arrive

int main() {                   // Le jeu commence ici.
  changer(TITRE);              // On dessine le titre.

  while (true) {               // La boucle du jeu :
    image();
    switch (etat) {            // la boucle ne fait plus qu'aiguiller
      case TITRE: titre(); break;
      case JEU:   jeu();   break;
      case PERDU: perdu(); break;
    }
  }
}
