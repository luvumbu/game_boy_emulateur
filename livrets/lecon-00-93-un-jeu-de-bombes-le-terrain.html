0.93. Un jeu de bombes — le terrain

Un nouveau jeu, façon Bomberman. D’abord le terrain : un cadre de X, et des piliers X sur une case sur deux (colonne ET ligne paires). Le joueur, le O, en (1, 1).

1. Ce qu’il faut comprendre

Un nouveau jeu : des bombes, comme dans Bomberman. Le joueur est un O, les ennemis seront des W, les murs sont des X. On le construit leçon après leçon ; ici, seulement le terrain, et le O posé à sa place de départ.

Le terrain : un cadre de X tout autour (comme au 0.91.3), et à l’intérieur, des piliers X, un sur deux, en quadrillage. Entre les piliers, des couloirs : c’est là qu’on se déplacera, et que les flammes des bombes passeront.

19 colonnes, de 0 à 18, et 17 lignes, de 0 à 16. Pourquoi 19 et pas 20 ? Pour que le cadre de droite (colonne 18) soit pair, comme celui de gauche (colonne 0). Ainsi, il y a un couloir des deux côtés de chaque pilier. La colonne 19 reste vide ; la ligne 17 servira au score.

Ce qui est nouveau ici : une case sur deux, avec % 2. c % 2 est le reste de la division par 2 (le % du 0.9) : 0 pour un nombre pair (0, 2, 4…), 1 pour un nombre impair (1, 3, 5…). Exemples : 6 % 2 = 0, car 6 = 3 × 2 + 0 ; 7 % 2 = 1, car 7 = 3 × 2 + 1.

Un pilier, c’est colonne paire ET ligne paire : c % 2 == 0 && l % 2 == 0 (&&, « et », le 0.75). En (2, 2) : oui, pilier. En (2, 3) : la ligne 3 est impaire, non : couloir. En (3, 2) : la colonne 3 est impaire, non : couloir. En (1, 1) : ni l’une ni l’autre, c’est la place du O.

Le cadre : l == 0 || l == 16 || c == 0 || c == 18 (||, « ou », le 0.91.3) : la première ou la dernière ligne, la première ou la dernière colonne.

Deux boucles, l’une dans l’autre (le 0.69.1) : la boucle des lignes (l, de 0 à 16) contient celle des colonnes (c, de 0 à 18). Pour chaque ligne, on passe sur toutes les colonnes : 17 × 19 = 323 cases, une par une. Déroulons : l = 0 : c = 0, 1, 2 … 18, tout est cadre. l = 1 : c = 0 cadre, 1 à 17 rien (ligne impaire), 18 cadre. l = 2 : c = 0 cadre, 1 rien, 2 pilier, 3 rien, 4 pilier… 18 cadre.

Sur le cadre, certaines cases sont aussi des piliers (par exemple (0, 0), ou (4, 16) : colonne et ligne paires). Le X y est posé deux fois : ce n’est pas grave, c’est le même X au même endroit.

Le compte : 68 X pour le cadre (19 en haut, 19 en bas, 15 à gauche, 15 à droite) et 56 piliers à l’intérieur (8 colonnes paires, de 2 à 16, × 7 lignes paires, de 2 à 14) : 124 X.

📖 Les mots de cette leçon — si tu débutes

  • accolades { } — Elles entourent un bloc : les lignes qui vont ensemble (le corps d’une fonction, d’une boucle, d’un « if »). Chaque « { » a son « } ».
  • affectation (=) — « x = 5; » : la boîte x prend la valeur 5. Ce n’est pas une égalité : c’est un rangement.
  • argument — Une valeur donnée à une fonction quand on l’appelle, entre ses parenthèses : dans texte(5, 8, "SALUT"), 5, 8 et "SALUT" sont les arguments.
  • bloc — Un groupe de lignes entre accolades { }, qui s’exécutent ensemble.
  • booléen (vrai / faux) — Le résultat d’une condition : vrai (1) ou faux (0). « true » veut dire vrai, « false » faux.
  • boucle — Des instructions qui se répètent : « while » (tant que…) ou « for » (pour un compteur qui va de… à…).
  • boucle du jeu — « while (true) { image(); … } » : ce qui se répète 60 fois par seconde, sans fin, pendant tout le jeu.
  • commentaire (//) — Tout ce qui suit « // » jusqu’au bout de la ligne : une phrase pour l’humain, que la console ignore.
  • condition — Une question dont la réponse est vrai ou faux : « score > 10 », « bouton(A) ». On la teste avec « if » ou « while ».
  • coordonnées — Deux nombres qui disent où : la colonne (vers la droite) puis la ligne (vers le bas), à partir de (0, 0) en haut à gauche.
  • for — Une boucle qui compte : « for (uint8_t i = 0; i < 5; i++) » fait 5 tours, i valant 0, 1, 2, 3 puis 4.
  • if (si) — Teste une condition : si elle est vraie, on fait le bloc qui suit.
  • image() — Attend l’image suivante. La console en montre 60 par seconde : c’est ce qui règle la vitesse d’un jeu.
  • #include — En haut du programme : « #include <texte> » demande la fonction texte() à la console ; « #include "fichier.cpp" » verse un de tes fichiers à cet endroit.
  • incrémenter (++) — « x++ » ou « x += 1 » : x augmente de 1. « x-- » : x diminue de 1.
  • indice — Le numéro d’une case dans un tableau, entre crochets : cases[3] est la quatrième case (on compte à partir de 0).
  • instruction — Un ordre donné à la console, terminé par un point-virgule : « texte(1, 1, "OK"); ».
  • main — « int main() { … } » : là où le programme commence. La console exécute d’abord la première ligne de main.
  • octet — Un nombre de 0 à 255 : la plus petite boîte de la mémoire. Une cartouche en a 32 768.
  • opérateurs de calcul — + plus, - moins, * fois, / divisé par (sans virgule : 7 / 2 donne 3), % le reste de la division (7 % 2 donne 1).
  • opérateurs de comparaison — == égal, != différent, < plus petit, > plus grand, <= plus petit ou égal, >= plus grand ou égal. Le résultat est vrai ou faux.
  • opérateurs logiques — && « et » (les deux doivent être vrais), || « ou » (un seul suffit), ! « pas ».
  • point-virgule (;) — Il termine une instruction, comme le point termine une phrase.
  • poser() — Met une tuile dans le décor, sur une case de la grille de 20 × 18 (32 × 32 en tout, avec la partie cachée).
  • uint8_t — Le genre de nombre de cette console : un entier de 0 à 255 (un octet). Au-delà, il repart à 0.
  • variable — Une boîte avec un nom, dans la mémoire, qui retient un nombre qu’on peut lire et changer.
  • while (tant que) — Répète un bloc tant qu’une condition est vraie.

2. le point d’entrée : c’est ici que la console arrive

int main() {
  // Deux boucles, l'une dans l'autre : chaque LIGNE, et dans chaque ligne,
  // chaque COLONNE. 17 lignes × 19 colonnes = 323 cases.
  for (uint8_t l = 0; l < 17; l++) {
    for (uint8_t c = 0; c < 19; c++) {

      // Le cadre : la première ou la dernière ligne, OU (||) la première
      // ou la dernière colonne.
      if (l == 0 || l == 16 || c == 0 || c == 18) {
        poser(c, l, ALPHABET[23]);
      }

      // NOUVEAU : les piliers. c % 2 : le reste de c divisé par 2.
      //   0 si c est PAIR (0, 2, 4…), 1 s'il est IMPAIR (1, 3, 5…).
      // Colonne paire ET (&&) ligne paire : un pilier.
      //   (2, 2) : pilier    (2, 3) : couloir    (3, 2) : couloir
      if (c % 2 == 0 && l % 2 == 0) {
        poser(c, l, ALPHABET[23]);
      }
    }
  }

  // Le joueur, le O, dans le coin en haut à gauche : (1, 1).
  poser(1, 1, ALPHABET[14]);

  while (true) {
    image();
  }
}
