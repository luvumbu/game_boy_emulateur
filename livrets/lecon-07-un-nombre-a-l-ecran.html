7. Un nombre à l’écran

`texte` écrit des lettres ; `nombre` écrit un calcul.

1. Ce qu’il faut comprendre

texte() ne sait écrire que ce qui est entre guillemets, décidé à la compilation. Un score qui change veut nombre().

nombre(colonne, ligne, valeur) écrit en base dix, sur trois chiffres par défaut — 042. Un quatrième argument dit combien on en veut : nombre(8, 4, vies, 1) écrit 3 tout seul.

Les fonctions de cette leçon — et le tuto de chacune

  • #include <texte> → 0.0.2. La fonction texte() — écrire un mot
  • #include <nombre> → 0.8.3. La fonction nombre() — écrire un nombre

2. Le programme, morceau par morceau

Le programme entier de la leçon, découpé comme l’œil le lit. Il fait 593 octets de cartouche.

Ce que le compilateur y a gravé, nommé — chaque morceau, sa taille, qui l’a demandé — et ce qu’il a laissé, parce que rien ne l’appelle :

1. ce que le programme raconte de lui-même

// CE PROGRAMME : affiche deux nombres rangés dans des variables : les vies et le score.
//
// Une VARIABLE est une case de mémoire qui porte un nom.
//   uint8_t vies = 3;  → crée une case « vies » (un nombre de 0 à 255) et y range 3.
// nombre(colonne, ligne, valeur) écrit un nombre à l'écran, sur 3 chiffres (003).
// nombre(colonne, ligne, valeur, 1) l'écrit sur 1 seul chiffre (3).

#include <texte>    // écrit un texte à l’écran
#include <nombre>   // écrit un nombre en chiffres

2. le point d’entrée : c’est ici que la console arrive

int main() {                  // Le jeu commence ici.
  uint8_t vies = 3;           // Une case « vies » qui contient 3.
  uint8_t score = 42;         // Une case « score » qui contient 42.

  texte(2, 4, "VIES");        // Le mot VIES...
  nombre(8, 4, vies, 1);      // ... et la valeur de vies, sur 1 chiffre : 3.

  texte(2, 6, "SCORE");       // Le mot SCORE...
  nombre(8, 6, score);        // ... et la valeur de score, sur 3 chiffres : 042.

  while (true) {              // Répète pour toujours :
    image();                  //   attend l'image suivante.
  }
}

3. Ce qui se passe, étape par étape

La cartouche a été compilée et exécutée pour de bon ; voici son écran aux instants qui comptent. Une image identique à la précédente n’est pas montrée — un programme qui ne bouge pas n’a qu’une seule image, et c’est la vérité sur ce programme.

4. Ce qu’on doit voir

« VIES 3 » et « SCORE 042 ».

5. Ce que la console répond

Ces contrôles ne sont pas décoratifs : ce sont ceux que verifier-tuto.mjs exige de cette leçon. Ils viennent d’être joués, et voici ce qu’ils ont mesuré.

  • un seul chiffre quand on le demande
  • trois chiffres par défaut, zéros compris
  • les étiquettes sont là
