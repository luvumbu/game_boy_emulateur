Chapitre 8 — Le son leçon 58 sur 143 difficulté 5 / 10 à la souris : partition

58. Une partition qui avance seule

`jouer()` la lance, et le jeu fait autre chose pendant ce temps.

1. Ce qu’il faut comprendre

C’est toute la différence avec la mélodie à la main : là-bas le programme menait chaque note ; ici jouer() lance la partition et elle avance toute seule.

Un pas par élément. "==" tient la note d’avant, "--" fait un silence. Le troisième argument de jouer() est le nombre d’images par pas — le tempo.

Dans la page, cette partition s’écrit à la souris, sur une portée. L’atelier produit exactement ces lignes.

Les fonctions de cette leçon — et le tuto de chacune

  • #include <Air> → 53.1. Air — écrire une musique
  • #include <jouer> → 53.2. La fonction jouer() — jouer un air tout seul
  • #include <texte> → 0.0.2. La fonction texte() — écrire un mot

1. ce que le programme raconte de lui-même

// CE PROGRAMME : joue une petite fanfare toute seule, une fois.
//
// Un Air est une liste de PAS de musique :
//   DO4 12 : la note do (octave 4), volume 12
//   ==     : la note d'avant continue (une note plus longue)
//   --     : silence
// jouer(voix, AIR, vitesse) : joue l'air sur la voix, un pas toutes les « vitesse » images.
// La console le joue TOUTE SEULE : le programme n'a plus rien à faire.

#include <Air>     // un air de musique, note par note
#include <jouer>   // joue un air tout seul
#include <texte>   // écrit un texte à l’écran

2. une mélodie — FANFARE

Air FANFARE = {
  "DO4 12", "==", "MI4 12", "==", "SOL4 12", "==", "DO5 12", "==", "==", "--",
};

3. le point d’entrée : c’est ici que la console arrive

int main() {                    // Le jeu commence ici.
  jouer(1, FANFARE, 8);         // Voix 1, un pas toutes les 8 images.
  texte(4, 8, "CA JOUE");

  while (true) {                // Répète pour toujours :
    image();                    //   attend l'image suivante (la musique continue seule).
  }
}

3. Ce qui se passe, étape par étape

La cartouche a été compilée et exécutée pour de bon ; voici son écran aux instants qui comptent. Une image identique à la précédente n’est pas montrée — un programme qui ne bouge pas n’a qu’une seule image, et c’est la vérité sur ce programme.

4. Ce qu’on doit voir

Une fanfare qui monte, sans que le programme s’en occupe.

5. Ce que la console répond

Ces contrôles ne sont pas décoratifs : ce sont ceux que verifier-tuto.mjs exige de cette leçon. Ils viennent d’être joués, et voici ce qu’ils ont mesuré.

  • le mot est écrit
  • la voix 1 joue
  • elle change de note toute seule (329, 392, 524 Hz)
  • et la mélodie monte
  • sans une ligne dans la boucle du programme

6. La même chose, à la souris

Cette leçon porte son atelier : le geste réécrit le programme ci-dessus, et la cartouche se refait dans la seconde. C’est le même texte, écrit autrement.
