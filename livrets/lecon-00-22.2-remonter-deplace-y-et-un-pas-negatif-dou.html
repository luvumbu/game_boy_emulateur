0.22.2. Remonter : deplace_y et un pas négatif — doublé, deux positions

La descente et la montée du A (colonne 0), puis celles du B (colonne 10).

1. Ce qu’il faut comprendre

C’est le 0.22 et le 0.22.1 réunis : les deux descentes-montées, chacune avec sa variable.

2. Le programme, morceau par morceau

Le programme entier de la leçon, découpé comme l’œil le lit. Il fait 1664 octets de cartouche.

1. une variable — pas

uint8_t pas = 5;

2. une variable — y

uint8_t y = 0;        // le A

3. une variable — yb

uint8_t yb = 0;       // le B

4. le point d’entrée : c’est ici que la console arrive

int main() {
  y = deplace_y(0, y, ALPHABET[0], pas);
  y = deplace_y(0, y, ALPHABET[0], -pas);       // le A (le 0.22)
  yb = deplace_y(10, yb, ALPHABET[1], pas);
  yb = deplace_y(10, yb, ALPHABET[1], -pas);    // le B (le 0.22.1)

  while (true) {
    image();
  }
}

3. Ce qui se passe, étape par étape

La cartouche a été compilée et exécutée pour de bon ; voici son écran aux instants qui comptent. Une image identique à la précédente n’est pas montrée — un programme qui ne bouge pas n’a qu’une seule image, et c’est la vérité sur ce programme.

4. Ce qu’on doit voir

Le A descend et remonte en colonne 0, puis le B en colonne 10.

5. Ce que la console répond

Ces contrôles ne sont pas décoratifs : ce sont ceux que verifier-tuto.mjs exige de cette leçon. Ils viennent d’être joués, et voici ce qu’ils ont mesuré.

  • le A passe par (0, 5)
  • le A finit en (0, 0) (0,0)
  • le B passe par (10, 5)
  • le B finit en (10, 0) (10,0)
