0.91.4. Le titre, puis le jeu — la pièce revient au hasard

Le 0.91.3, mais la pièce ramassée ne disparaît plus : elle réapparaît au hasard, dans le cadre. 1 + hasard() % 18 pour la colonne, 1 + hasard() % 15 pour la ligne.

1. Ce qu’il faut comprendre

C’est le 0.91.3, avec une chose en plus : quand le A prend le P, le P ne part plus hors de l’écran (px = 20). Il réapparaît ailleurs, au hasard, et on peut le ramasser encore et encore pendant les 30 secondes.

hasard(), on la connaît (le 0.81.2) : elle rend un nombre imprévisible, de 0 à 255. Au 0.81.2, hasard() % 20 donnait une colonne de 0 à 19 : tout l’écran.

Ce qui est nouveau ici : rester DANS le cadre. Les colonnes 0 et 19 sont des murs X : une pièce posée là effacerait le mur, et le A ne pourrait jamais l’atteindre. La pièce doit donc tomber entre la colonne 1 et la colonne 18 : 18 colonnes possibles.

hasard() % 18 garde le reste de la division par 18 : un nombre de 0 à 17. Exemples : 137 = 7 × 18 + 11, le reste est 11 ; 36 = 2 × 18 + 0, le reste est 0 ; 17 = 0 × 18 + 17, le reste est 17.

Le 1 + décale tout d’une case : 0 devient 1, 17 devient 18. 1 + hasard() % 18 donne donc une colonne de 1 à 18 : jamais sur un mur. Avec 137 : 1 + 11 = 12.

Pour la ligne, pareil : les lignes 0 et 16 sont des murs, la pièce va de la ligne 1 à la ligne 15 : 15 lignes possibles. hasard() % 15 donne 0 à 14, et 1 + hasard() % 15 donne 1 à 15.

Le calcul se fait dans l’ordre des maths : % passe avant +, comme × avant +. 1 + hasard() % 18, c’est « le reste d’abord, puis on ajoute 1 ».

Puis poser(px, py, ALPHABET[15]) dessine le nouveau P à sa place. L’ancien n’a pas besoin d’être effacé : le A est dessus.

Dans nouvellePartie(), rien ne change : le P revient en (15, 8), d’où qu’il soit.

📖 Les mots de cette leçon — si tu débutes

  • accolades { } — Elles entourent un bloc : les lignes qui vont ensemble (le corps d’une fonction, d’une boucle, d’un « if »). Chaque « { » a son « } ».
  • affectation (=) — « x = 5; » : la boîte x prend la valeur 5. Ce n’est pas une égalité : c’est un rangement.
  • argument — Une valeur donnée à une fonction quand on l’appelle, entre ses parenthèses : dans texte(5, 8, "SALUT"), 5, 8 et "SALUT" sont les arguments.
  • bloc — Un groupe de lignes entre accolades { }, qui s’exécutent ensemble.
  • booléen (vrai / faux) — Le résultat d’une condition : vrai (1) ou faux (0). « true » veut dire vrai, « false » faux.
  • boucle — Des instructions qui se répètent : « while » (tant que…) ou « for » (pour un compteur qui va de… à…).
  • boucle du jeu — « while (true) { image(); … } » : ce qui se répète 60 fois par seconde, sans fin, pendant tout le jeu.
  • bouton() — Une fonction de la console qui dit si un bouton de la manette est enfoncé : 1 oui, 0 non. Les boutons : A, B, HAUT, BAS, GAUCHE, DROITE, START, SELECT.
  • chaîne de caractères (texte) — Des lettres entre guillemets, "COMME CECI" : un texte pris tel quel. La police de la console n’a que des majuscules, sans accents.
  • commentaire (//) — Tout ce qui suit « // » jusqu’au bout de la ligne : une phrase pour l’humain, que la console ignore.
  • condition — Une question dont la réponse est vrai ou faux : « score > 10 », « bouton(A) ». On la teste avec « if » ou « while ».
  • coordonnées — Deux nombres qui disent où : la colonne (vers la droite) puis la ligne (vers le bas), à partir de (0, 0) en haut à gauche.
  • fonction — Un groupe d’instructions qui a un nom, qu’on lance en écrivant son nom et des parenthèses. Celles de la console (texte, poser…) sont toutes prêtes ; on peut écrire les siennes.
  • for — Une boucle qui compte : « for (uint8_t i = 0; i < 5; i++) » fait 5 tours, i valant 0, 1, 2, 3 puis 4.
  • hasard() — Une fonction de la console qui rend un nombre au hasard, de 0 à 255.
  • if (si) — Teste une condition : si elle est vraie, on fait le bloc qui suit.
  • image() — Attend l’image suivante. La console en montre 60 par seconde : c’est ce qui règle la vitesse d’un jeu.
  • #include — En haut du programme : « #include <texte> » demande la fonction texte() à la console ; « #include "fichier.cpp" » verse un de tes fichiers à cet endroit.
  • incrémenter (++) — « x++ » ou « x += 1 » : x augmente de 1. « x-- » : x diminue de 1.
  • indice — Le numéro d’une case dans un tableau, entre crochets : cases[3] est la quatrième case (on compte à partir de 0).
  • instruction — Un ordre donné à la console, terminé par un point-virgule : « texte(1, 1, "OK"); ».
  • main — « int main() { … } » : là où le programme commence. La console exécute d’abord la première ligne de main.
  • octet — Un nombre de 0 à 255 : la plus petite boîte de la mémoire. Une cartouche en a 32 768.
  • opérateurs de calcul — + plus, - moins, * fois, / divisé par (sans virgule : 7 / 2 donne 3), % le reste de la division (7 % 2 donne 1).
  • opérateurs de comparaison — == égal, != différent, < plus petit, > plus grand, <= plus petit ou égal, >= plus grand ou égal. Le résultat est vrai ou faux.
  • opérateurs logiques — && « et » (les deux doivent être vrais), || « ou » (un seul suffit), ! « pas ».
  • point-virgule (;) — Il termine une instruction, comme le point termine une phrase.
  • poser() — Met une tuile dans le décor, sur une case de la grille de 20 × 18 (32 × 32 en tout, avec la partie cachée).
  • texte() — Écrit des lettres à l’écran, sur la grille de 20 colonnes et 18 lignes : texte(colonne, ligne, "MOT").
  • uint8_t — Le genre de nombre de cette console : un entier de 0 à 255 (un octet). Au-delà, il repart à 0.
  • variable — Une boîte avec un nom, dans la mémoire, qui retient un nombre qu’on peut lire et changer.
  • void — Devant une fonction : elle ne rend rien, elle agit seulement.
  • while (tant que) — Répète un bloc tant qu’une condition est vraie.

void nouvellePartie() {
  x = 5;                          // le A revient à sa place
  y = 8;
  px = 15;                        // le P revient en (15, 8), d'où qu'il soit
  py = 8;
  ax = 5;                         // et sa place d'avant, la même
  ay = 8;
  score = 0;                      // pas encore de pièce
  temps = 30;                     // 30 secondes de nouveau
  ecran = 1;                      // on est sur le JEU
  viderEcran();
  poser(px, py, ALPHABET[15]);

  // ---- Le cadre de murs, des X tout autour du terrain (le 0.91.3) ----
  //
  //   colonne : 0 1 2 …           19
  //   ligne 0 : X X X X X X … X X X     le haut : ligne 0, colonnes 0 à 19
  //   ligne 1 : X                 X
  //   …         X   A        P    X     les côtés : colonnes 0 et 19
  //   ligne 15: X                 X
  //   ligne 16: X X X X X X … X X X     le bas : ligne 16
  //   ligne 17: SCORE 000  TEMPS 030    la ligne 17 reste aux nombres
  //
  // ALPHABET[23] : la 24e lettre (on compte depuis 0), le X.
  for (uint8_t c = 0; c < 20; c++) {
    poser(c, 0, ALPHABET[23]);        // le haut
    poser(c, 16, ALPHABET[23]);       // le bas
  }
  for (uint8_t l = 1; l < 16; l++) {
    poser(0, l, ALPHABET[23]);        // le côté gauche
    poser(19, l, ALPHABET[23]);       // le côté droit
  }

  texte(0, 17, "SCORE");
  texte(11, 17, "TEMPS");
}

  couleurTexte(31, 16, 0);

  while (true) {
    image();

      nouvellePartie();               // la première partie
    }

      ay = y;

      // …et s'il est arrivé SUR le cadre (colonne 0 ou 19, ligne 0 ou 16) :
      //   1. on remet le X, que le A venait de recouvrir ;
      //   2. le A revient à sa place d'avant, et s'y pose.
      // || veut dire « OU » : une seule des quatre suffit.
      if (x == 0 || x == 19 || y == 0 || y >= 16) {
        poser(x, y, ALPHABET[23]);             // le mur revient
        x = ax;                                // le A recule
        y = ay;
        poser(x, y, ALPHABET[0]);
      }
      if (x == px && y == py) {                // le A sur le P : ramassée (le 0.81)

        // ---- NOUVEAU : la pièce réapparaît AU HASARD, mais DANS le cadre ----
        //
        //   px = 1 + hasard() % 18;
        //        |   |        |
        //        |   |        +-- % 18 : le reste de la division par 18, de 0 à 17.
        //        |   |            Exemple : hasard() rend 137 ; 137 = 7 × 18 + 11 ;
        //        |   |            le reste est 11.
        //        |   +----------- un nombre imprévisible, de 0 à 255 (le 0.81.2)
        //        +--------------- + 1 : on décale de 0…17 à 1…18 → 11 + 1 = 12.
        //
        // Pourquoi pas % 20 comme au 0.81.2 ? Les colonnes 0 et 19 sont des murs X :
        // la pièce doit rester de 1 à 18. Les lignes 0 et 16 aussi sont des murs :
        // la pièce doit rester de 1 à 15, d'où 1 + hasard() % 15.
        px = 1 + hasard() % 18;                // une colonne : 1 à 18
        py = 1 + hasard() % 15;                // une ligne : 1 à 15
        poser(px, py, ALPHABET[15]);           // le nouveau P apparaît là
      }
      nombre(6, 17, score);
      nombre(17, 17, temps);
    }

    if (ecran == 1 && chaque(1000)) {
      temps = temps - 1;
      if (temps == 0) {
