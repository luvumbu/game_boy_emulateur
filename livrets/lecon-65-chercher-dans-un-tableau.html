65. Chercher dans un tableau

Sortir dès qu’on a trouvé, et réserver une valeur pour « pas trouvé ».

1. Ce qu’il faut comprendre

break sort de la boucle ; continue passerait au tour suivant.

ou = 255 sert de « pas trouvé ». Sur un octet il n’y a pas de valeur spéciale, alors on en réserve une — et l’on choisit celle qui ne peut pas être un index valide, puisqu’un tableau fait 256 cases au plus.

Les fonctions de cette leçon — et le tuto de chacune

  • #include <texte> → 0.0.2. La fonction texte() — écrire un mot
  • #include <nombre> → 0.8.3. La fonction nombre() — écrire un nombre

1. ce que le programme raconte de lui-même

// CE PROGRAMME : remplit un tableau de 8 nombres (0, 3, 6, 9 ...), y cherche
// le nombre 12, et affiche à quelle case il l'a trouvé.
//
// break : sort de la boucle TOUT DE SUITE (inutile de continuer à chercher).

#include <texte>    // écrit un texte à l’écran
#include <nombre>   // écrit un nombre en chiffres

2. un tableau — valeurs

uint8_t valeurs[8];               // 8 cases : valeurs[0] à valeurs[7].

3. le point d’entrée : c’est ici que la console arrive

int main() {                      // Le jeu commence ici.
  for (uint8_t i = 0; i < 8; i++) valeurs[i] = i * 3;
                                  // 0, 3, 6, 9, 12, 15, 18, 21

  uint8_t cherche = 12;           // Le nombre qu'on cherche.
  uint8_t ou = 255;               // Où on l'a trouvé. 255 = « pas trouvé » (une valeur impossible).

  for (uint8_t i = 0; i < 8; i++) {                      // Chaque case i :
    if (valeurs[i] == cherche) { ou = i; break; }        //   c'est lui ? on note i, et on sort.
  }                                                      // valeurs[4] vaut 12 → ou = 4.

  texte(2, 6, "TROUVE EN");
  nombre(13, 6, ou);              // Affiche 004.

  while (true) {                  // Répète pour toujours :
    image();                      //   attend l'image suivante.
  }
}

3. Ce qui se passe, étape par étape

La cartouche a été compilée et exécutée pour de bon ; voici son écran aux instants qui comptent. Une image identique à la précédente n’est pas montrée — un programme qui ne bouge pas n’a qu’une seule image, et c’est la vérité sur ce programme.

4. Ce qu’on doit voir

« TROUVE EN 004 » — 12 est bien la cinquième valeur.

5. Ce que la console répond

Ces contrôles ne sont pas décoratifs : ce sont ceux que verifier-tuto.mjs exige de cette leçon. Ils viennent d’être joués, et voici ce qu’ils ont mesuré.

  • la recherche a abouti (4)
  • ce n’est pas resté à « pas trouvé »
  • et le résultat est affiché
  • le tableau contient bien des multiples de trois
