0.30.2. Un pas sans attendre : un_pas — doublé, deux positions

Le A (ligne 0) et le B (ligne 8) avancent EN MÊME TEMPS : deux un_pas dans la même image.

1. Ce qu’il faut comprendre

C’est le 0.30 et le 0.30.1 réunis : deux un_pas dans la même boucle.

Ensemble, cette fois : un_pas n’attend pas, les deux pas se font dans la même image. Les deux lettres avancent côte à côte.

2. Le programme, morceau par morceau

Le programme entier de la leçon, découpé comme l’œil le lit. Il fait 1678 octets de cartouche.

1. une variable — x

uint8_t x = 0;       // la colonne du A

2. une variable — y

uint8_t y = 0;       // sa ligne

3. une variable — xb

uint8_t xb = 0;       // la colonne du B

4. une variable — yb

uint8_t yb = 8;       // sa ligne

5. une variable — images

uint8_t images = 0;   // le chronomètre

6. le point d’entrée : c’est ici que la console arrive

int main() {
  poser(x, y, ALPHABET[0]);
  poser(xb, yb, ALPHABET[1]);
  while (true) {
    image();
    images++;
    if (images == 15) {
      images = 0;
      un_pas(x, y, ALPHABET[0], 1, 0);
      un_pas(xb, yb, ALPHABET[1], 1, 0);
    }
  }
}

3. Ce qui se passe, étape par étape

La cartouche a été compilée et exécutée pour de bon ; voici son écran aux instants qui comptent. Une image identique à la précédente n’est pas montrée — un programme qui ne bouge pas n’a qu’une seule image, et c’est la vérité sur ce programme.

4. Ce qu’on doit voir

Le A et le B avancent ensemble, l’un sur la ligne 0, l’autre sur la ligne 8.
