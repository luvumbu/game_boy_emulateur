0.27.2. Le carré avec deplace — doublé, deux positions

Les deux : le A à gauche (départ (0, 0)), puis le B à droite (départ (9, 0)).

1. Ce qu’il faut comprendre

C’est le 0.27 et le 0.27.1 réunis : les dix lignes du A, puis les dix du B.

Les deux trajets ne se touchent pas : le A reste dans les colonnes 0 à 10, le B dans les colonnes 9 à 19, sur d’autres cases.

Les fonctions de cette leçon — et le tuto de chacune

  • #include <deplace> → 0.25.3. La fonction deplace() — avancer sur les deux axes
  • #include <ALPHABET> → 0.1.4. ALPHABET — les lettres de la police

📖 Les mots de cette leçon — si tu débutes

  • accolades { } — Elles entourent un bloc : les lignes qui vont ensemble (le corps d’une fonction, d’une boucle, d’un « if »). Chaque « { » a son « } ».
  • affectation (=) — « x = 5; » : la boîte x prend la valeur 5. Ce n’est pas une égalité : c’est un rangement.
  • argument — Une valeur donnée à une fonction quand on l’appelle, entre ses parenthèses : dans texte(5, 8, "SALUT"), 5, 8 et "SALUT" sont les arguments.
  • bloc — Un groupe de lignes entre accolades { }, qui s’exécutent ensemble.
  • booléen (vrai / faux) — Le résultat d’une condition : vrai (1) ou faux (0). « true » veut dire vrai, « false » faux.
  • boucle — Des instructions qui se répètent : « while » (tant que…) ou « for » (pour un compteur qui va de… à…).
  • boucle du jeu — « while (true) { image(); … } » : ce qui se répète 60 fois par seconde, sans fin, pendant tout le jeu.
  • commentaire (//) — Tout ce qui suit « // » jusqu’au bout de la ligne : une phrase pour l’humain, que la console ignore.
  • condition — Une question dont la réponse est vrai ou faux : « score > 10 », « bouton(A) ». On la teste avec « if » ou « while ».
  • image() — Attend l’image suivante. La console en montre 60 par seconde : c’est ce qui règle la vitesse d’un jeu.
  • #include — En haut du programme : « #include <texte> » demande la fonction texte() à la console ; « #include "fichier.cpp" » verse un de tes fichiers à cet endroit.
  • indice — Le numéro d’une case dans un tableau, entre crochets : cases[3] est la quatrième case (on compte à partir de 0).
  • instruction — Un ordre donné à la console, terminé par un point-virgule : « texte(1, 1, "OK"); ».
  • main — « int main() { … } » : là où le programme commence. La console exécute d’abord la première ligne de main.
  • octet — Un nombre de 0 à 255 : la plus petite boîte de la mémoire. Une cartouche en a 32 768.
  • point-virgule (;) — Il termine une instruction, comme le point termine une phrase.
  • uint8_t — Le genre de nombre de cette console : un entier de 0 à 255 (un octet). Au-delà, il repart à 0.
  • variable — Une boîte avec un nom, dans la mémoire, qui retient un nombre qu’on peut lire et changer.
  • while (tant que) — Répète un bloc tant qu’une condition est vraie.

2. Le programme, morceau par morceau

Le programme entier de la leçon, découpé comme l’œil le lit. Il fait 1416 octets de cartouche.

Ce que le compilateur y a gravé, nommé — chaque morceau, sa taille, qui l’a demandé — et ce qu’il a laissé, parce que rien ne l’appelle :

Gravé dans la cartouche :

  deplace()       236 o  ← main()  — une fonction fournie par le langage
  main()          289 o  ← démarrage  — ta fonction
  VBlank            8 o  ← la console, à chaque image  — compte les images, 60 fois par seconde
  AttendreImage    28 o  ← image()  — attend l’image suivante
  AttendreVBlank   16 o  ← démarrage  — attend que l’écran soit libre
  AttendreAcces    12 o  ← EffacerCases  — attend de pouvoir écrire une case

  EffacerCases     12 o  ← effacer()  — efface des cases

int main() {          // Le programme commence ici.
  // deplace(colonne, ligne, tuile, pasX, pasY) : les deux axes à la fois.
  // 1. Le A (ALPHABET[0]), depuis (0, 0) :      pasX  pasY
  deplace(x, y, ALPHABET[0], 5, 5);       // la diagonale : (5, 5)
  deplace(x, y, ALPHABET[0], 5, 0);       // à droite     : (10, 5)
  deplace(x, y, ALPHABET[0], 0, 5);       // en bas       : (10, 10)
  deplace(x, y, ALPHABET[0], -5, 0);      // à gauche     : (5, 10)
  deplace(x, y, ALPHABET[0], 0, -5);      // en haut      : (5, 5)
  // 2. Le B (ALPHABET[1]), depuis (9, 0), avec ses variables xb et yb :
  deplace(xb, yb, ALPHABET[1], 5, 5);     // (14, 5)
  deplace(xb, yb, ALPHABET[1], 5, 0);     // (19, 5)
  deplace(xb, yb, ALPHABET[1], 0, 5);     // (19, 10)
  deplace(xb, yb, ALPHABET[1], -5, 0);    // (14, 10)
  deplace(xb, yb, ALPHABET[1], 0, -5);    // (14, 5)

  while (true) {      // La boucle de jeu, pour toujours :
    image();          //   attendre l'image suivante.
  }
}
