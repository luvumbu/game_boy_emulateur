0.56.2. Changer de vitesse en route — doublé, deux positions

Le A vite puis lentement, et le B aussi : chaque vitesse vaut jusqu’à la suivante.

1. Ce qu’il faut comprendre

C’est le 0.56 et le 0.56.1 réunis : les deux lettres, chacune avec ses deux vitesses.

2. Le programme, morceau par morceau

Le programme entier de la leçon, découpé comme l’œil le lit. Il fait 1664 octets de cartouche.

1. une variable — x

uint8_t x = 0;        // le A

2. une variable — xb

uint8_t xb = 0;       // le B

3. le point d’entrée : c’est ici que la console arrive

int main() {
  vitesse(100);
  deplace_x(x, 0, ALPHABET[0], 5);
  deplace_x(xb, 8, ALPHABET[1], 5);    // toujours à 100
  vitesse(500);
  deplace_x(x, 0, ALPHABET[0], -5);
  deplace_x(xb, 8, ALPHABET[1], -5);   // toujours à 500

  while (true) {
    image();
  }
}

3. Ce qui se passe, étape par étape

La cartouche a été compilée et exécutée pour de bon ; voici son écran aux instants qui comptent. Une image identique à la précédente n’est pas montrée — un programme qui ne bouge pas n’a qu’une seule image, et c’est la vérité sur ce programme.

4. Ce qu’on doit voir

Le A puis le B filent à droite ; puis le A et le B reviennent lentement.

5. Ce que la console répond

Ces contrôles ne sont pas décoratifs : ce sont ceux que verifier-tuto.mjs exige de cette leçon. Ils viennent d’être joués, et voici ce qu’ils ont mesuré.

  • le A finit en (0, 0) (0,0)
  • le B finit en (0, 8) (0,8)
