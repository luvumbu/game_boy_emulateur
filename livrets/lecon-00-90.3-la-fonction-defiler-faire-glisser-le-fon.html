0.90.3. La fonction defiler() — faire glisser le fond

#include <defiler> : defiler(x, y) décale tout le fond de x pixels vers la gauche et y vers le haut.

1. Ce qu’il faut comprendre

Ce qu’elle fait : defiler(x, y) fait glisser tout le fond : l’écran montre la carte à partir du pixel (x, y). La carte fait 256 pixels de côté et revient toute seule au début.

La ligne à écrire : #include <defiler>.

Ses arguments : le décalage en pixels, en x puis en y.

Ce qu’elle coûte : environ 75 octets, avec la mise en place de l’écran. L’appel seul : quatre octets.

Essaie : fais grandir y au lieu de x : le mot monte.

On retrouve defiler dans 10 leçons

0.90.4, 0.95.1, 52, 61, 84, 85, 124, 125, 130, 137

2. Le programme, morceau par morceau

Le programme entier de la leçon, découpé comme l’œil le lit. Il fait 331 octets de cartouche.

Ce que le compilateur y a gravé, nommé — chaque morceau, sa taille, qui l’a demandé — et ce qu’il a laissé, parce que rien ne l’appelle :

1. ce que le programme raconte de lui-même

// ---- #include <defiler> : faire glisser le fond ----
// À chaque image, x grandit d'un pixel : tout le fond glisse vers la gauche,
// jusqu'à 60 pixels (7 cases et demie), puis s'arrête.

#include <texte>
#include <defiler>   // defiler() : décaler tout le fond

2. une variable — x

uint8_t x = 0;

3. le point d’entrée : c’est ici que la console arrive

int main() {
  texte(8, 8, "GLISSE");

  while (true) {
    image();
    if (x < 60) {
      x = x + 1;      // un pixel de plus
    }
    defiler(x, 0);    // le fond se décale de x pixels
  }
}

3. Ce qui se passe, étape par étape

La cartouche a été compilée et exécutée pour de bon ; voici son écran aux instants qui comptent. Une image identique à la précédente n’est pas montrée — un programme qui ne bouge pas n’a qu’une seule image, et c’est la vérité sur ce programme.

4. Ce qu’on doit voir

Le mot GLISSE glisse vers la gauche, puis s’arrête.

5. Ce que la console répond

Ces contrôles ne sont pas décoratifs : ce sont ceux que verifier-tuto.mjs exige de cette leçon. Ils viennent d’être joués, et voici ce qu’ils ont mesuré.

  • le fond est décalé (17 puis 27)
  • et il avance d’un pixel par image (+10)
