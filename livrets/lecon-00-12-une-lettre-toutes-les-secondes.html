0.12. Une lettre toutes les secondes

Écrire DANS la boucle de jeu, et compter les images pour mesurer le temps.

1. Ce qu’il faut comprendre

Jusqu’ici, on écrivait avant la boucle de jeu, une fois pour toutes. Ici, on écrit dedans : à chaque image, la case (0, 0) reçoit la lettre du moment.

La console ne connaît ni les secondes ni les millisecondes : elle compte les images. Il y en a 60 par seconde ; une image dure donc 1000 ÷ 60 ≈ 16,7 millisecondes. image() attend l’image suivante : chaque tour de boucle dure une image.

IMAGES_PAR_SECONDE et SECONDES donnent un nom à ces nombres. SECONDES * IMAGES_PAR_SECONDE vaut 1 × 60 = 60 : quand images atteint 60, une seconde est passée. Pour changer la vitesse, on ne touche qu’à SECONDES.

Limite : images est un uint8_t, qui ne dépasse pas 255. On compte donc au plus 255 images, environ 4 secondes : SECONDES = 5 donnerait 300, trop grand. Le chapitre suivant montre attendre(), qui n’a pas cette limite.

Chaque nouvelle lettre écrase la précédente, comme au 0.3. Après Z, lettre revient à 0 : on repart de A.

Les fonctions de cette leçon — et le tuto de chacune

  • #include <ALPHABET> → 0.1.4. ALPHABET — les lettres de la police
  • #include <poser> → 0.1.3. La fonction poser() — poser une tuile

2. Le programme, morceau par morceau

Le programme entier de la leçon, découpé comme l’œil le lit. Il fait 892 octets de cartouche.

Ce que le compilateur y a gravé, nommé — chaque morceau, sa taille, qui l’a demandé — et ce qu’il a laissé, parce que rien ne l’appelle :

Gravé dans la cartouche :
  démarrage        55 o  ← la console, à l’allumage  — la mise en route de la console
  main()           49 o  ← démarrage  — ta fonction
  VBlank            8 o  ← la console, à chaque image  — compte les images, 60 fois par seconde
  AttendreImage    28 o  ← image()  — attend l’image suivante
  AttendreVBlank   16 o  ← démarrage  — attend que l’écran soit libre
  CopierTuiles     18 o  ← démarrage  — copie les lettres et les dessins en mémoire vidéo
  EffacerCarte     14 o  ← démarrage  — vide les deux cartes de l’écran
  Tuiles          704 o  ← CopierTuiles  — la police entière
Lettres gravées : toutes (poser() reçoit un numéro calculé)
Pas gravé (jamais appelé) : AvancerAirs, AttendreAcces, AttendreFinVBlank, AdresseCase, EffacerCases, EcrireTexte, EcrireNombre, Diviser, Reste, Multiplier, DecalerGauche, DecalerDroite, RangerLutins, InstallerTransfert, Hasard, EffacerFond, EffacerPanneau, LireManette, DonneesTransfert, Notes
Fonctions du langage appelées :
  poser() × 1    12 o sur place, dans main()
  image() × 1     3 o sur place, dans main()  + AttendreImage (28 o)

1. ce que le programme raconte de lui-même

#include <ALPHABET>   // les lettres de la police : ALPHABET[0] est le A
#include <poser>      // pose une tuile sur une case du fond

2. une constante — IMAGES_PAR_SECONDE

const uint8_t IMAGES_PAR_SECONDE = 60;   // la console affiche 60 images par seconde

3. une constante — SECONDES

const uint8_t SECONDES = 1;              // le temps entre deux lettres, en secondes

4. une variable — lettre

uint8_t lettre = 0;   // l'indice de la lettre affichée

5. une variable — images

uint8_t images = 0;   // les images comptées depuis la dernière lettre

6. le point d’entrée : c’est ici que la console arrive

int main() {
  while (true) {
    image();          // attend l'image suivante : environ 16,7 ms
    images++;         // une image de plus

    if (images == SECONDES * IMAGES_PAR_SECONDE) {  // 1 × 60 = 60 images = 1 seconde
      images = 0;                                   // on recommence à compter
      lettre++;                                     // la lettre suivante
      if (lettre == sizeof(ALPHABET)) lettre = 0;   // après Z, on revient à A
    }

    poser(0, 0, ALPHABET[lettre]);   // la même case : la lettre écrase la précédente
  }
}

3. Ce qui se passe, étape par étape

La cartouche a été compilée et exécutée pour de bon ; voici son écran aux instants qui comptent. Une image identique à la précédente n’est pas montrée — un programme qui ne bouge pas n’a qu’une seule image, et c’est la vérité sur ce programme.
