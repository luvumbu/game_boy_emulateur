0.31.1. Deux lettres à la fois — de base, ailleurs

Le 0.31 déplacé : le A part de la colonne 10, le B descend en colonne 10.

1. Ce qu’il faut comprendre

C’est le 0.31, avec une autre lettre, le B (ALPHABET[1], la 2e lettre), et une autre place : la colonne 10 : le A part de (10, 0) vers la droite, le B de (10, 2) vers le bas.

Leurs chemins ne se croisent pas : le A reste sur la ligne 0, le B commence à la ligne 2.

C’est la version de base : une seule lettre, à la deuxième place. Le 0.31.2 met les deux ensemble.

2. Le programme, morceau par morceau

Le programme entier de la leçon, découpé comme l’œil le lit. Il fait 1699 octets de cartouche.

1. une variable — xa

uint8_t xa = 10;       // la colonne du A

2. une variable — ya

uint8_t ya = 0;       // sa ligne

3. une variable — xb

uint8_t xb = 10;       // la colonne du B

4. une variable — yb

uint8_t yb = 2;       // sa ligne

5. une variable — images

uint8_t images = 0;   // le chronomètre

6. le point d’entrée : c’est ici que la console arrive

int main() {
  poser(xa, ya, ALPHABET[0]);
  poser(xb, yb, ALPHABET[1]);
  while (true) {
    image();
    images++;
    if (images == 15) {
      images = 0;
      un_pas(xa, ya, ALPHABET[0], 1, 0);
      if (yb < 16) un_pas(xb, yb, ALPHABET[1], 0, 1);
    }
  }
}

3. Ce qui se passe, étape par étape

La cartouche a été compilée et exécutée pour de bon ; voici son écran aux instants qui comptent. Une image identique à la précédente n’est pas montrée — un programme qui ne bouge pas n’a qu’une seule image, et c’est la vérité sur ce programme.

4. Ce qu’on doit voir

Un A qui file à droite depuis le milieu de la ligne du haut, un B qui descend en colonne 10.

5. Ce que la console répond

Ces contrôles ne sont pas décoratifs : ce sont ceux que verifier-tuto.mjs exige de cette leçon. Ils viennent d’être joués, et voici ce qu’ils ont mesuré.

  • le A va jusqu’au bord : 19 (xa = 19)
  • le B s’arrête en ligne 16 (yb = 16)
