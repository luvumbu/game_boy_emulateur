0.4. L’alphabet à la main, jusqu’au bout de la ligne

Une lettre par case : au bout de 20, la ligne est pleine.

1. Ce qu’il faut comprendre

Chaque lettre prend une case de 8 pixels de large. L’écran en fait 160 : 20 lettres remplissent donc toute la ligne, de la colonne 0 à la colonne 19.

On s’arrête à T, la 20e lettre. Il n’y a pas de colonne 20 : texte(20, 0, "U") est refusé par le compilateur, qui répond que l’écran fait 20 colonnes.

Vingt lignes presque identiques : c’est long à écrire, et c’est exactement ce qu’une boucle saura faire à notre place.

2. Le programme, morceau par morceau

Le programme entier de la leçon, découpé comme l’œil le lit. Il fait 1513 octets de cartouche.

1. le point d’entrée : c’est ici que la console arrive

int main() {
  texte(0, 0, "A");
  texte(1, 0, "B");
  texte(2, 0, "C");
  texte(3, 0, "D");
  texte(4, 0, "E");
  texte(5, 0, "F");
  texte(6, 0, "G");
  texte(7, 0, "H");
  texte(8, 0, "I");
  texte(9, 0, "J");
  texte(10, 0, "K");
  texte(11, 0, "L");
  texte(12, 0, "M");
  texte(13, 0, "N");
  texte(14, 0, "O");
  texte(15, 0, "P");
  texte(16, 0, "Q");
  texte(17, 0, "R");
  texte(18, 0, "S");
  texte(19, 0, "T");   // colonne 19 : la dernière de la ligne
  // On s'arrête ici : l'écran fait 20 colonnes (de 0 à 19).
  // 20 lettres de 8 pixels = 160 pixels : toute la largeur de l'écran.
  // (si on dépasse : texte(20, 0, "U") est refusé par le compilateur,
  //  qui répond « l'écran fait 20 colonnes et 18 lignes ; 20,0 est dehors »)

  while (true) {
    image();
  }
}

3. Ce qui se passe, étape par étape

La cartouche a été compilée et exécutée pour de bon ; voici son écran aux instants qui comptent. Une image identique à la précédente n’est pas montrée — un programme qui ne bouge pas n’a qu’une seule image, et c’est la vérité sur ce programme.

4. Ce qu’on doit voir

A à T sur toute la première ligne, d’un bord à l’autre de l’écran.

5. Ce que la console répond

Ces contrôles ne sont pas décoratifs : ce sont ceux que verifier-tuto.mjs exige de cette leçon. Ils viennent d’être joués, et voici ce qu’ils ont mesuré.

  • la ligne 0 est pleine : A à T
  • rien ne déborde sur la ligne 1
