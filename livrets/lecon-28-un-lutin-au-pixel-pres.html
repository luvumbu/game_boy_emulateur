28. Un lutin, au pixel près

Ce qui sépare un jeu d’action d’un jeu de cases.

1. Ce qu’il faut comprendre

Le décor vit sur une grille de huit pixels. Un personnage, non : s’il ne pouvait s’arrêter que sur des multiples de huit, il ne sauterait pas, il se téléporterait.

sprite(numero, x, y, tuile) pose un carré de huit sur huit où l’on veut. Le matériel en a quarante, numérotés de 0 à 39.

Il n’y a rien à faire pour l’effacer : on le repose ailleurs à chaque image, et il a bougé.

2. Le programme, morceau par morceau

Le programme entier de la leçon, découpé comme l’œil le lit. Il fait 1554 octets de cartouche.

1. un dessin — BALLE

Tuile BALLE = {
  "00333300",
  "03222230",
  "32222223",
  "32222223",
  "32222223",
  "32222223",
  "03222230",
  "00333300",
};

2. le point d’entrée : c’est ici que la console arrive

int main() {
  uint8_t x = 20;
  uint8_t y = 60;

  texte(3, 2, "CROIX POUR BOUGER");

  while (true) {
    image();

    if (bouton(DROITE) && x < 150) x += 2;
    if (bouton(GAUCHE) && x > 2) x -= 2;
    if (bouton(BAS) && y < 135) y += 2;
    if (bouton(HAUT) && y > 2) y -= 2;

    sprite(0, x, y, BALLE);
  }

  return 0;
}

3. Ce qui se passe, étape par étape

La cartouche a été compilée et exécutée pour de bon ; voici son écran aux instants qui comptent. Une image identique à la précédente n’est pas montrée — un programme qui ne bouge pas n’a qu’une seule image, et c’est la vérité sur ce programme.

4. Ce que les touches changent

Chaque bouton que le programme lit a été enfoncé douze images, puis relâché. Voici l’écran juste après.

5. Ce qu’on doit voir

Une boule qu’on déplace à la croix, sans à-coups.

6. Ce que la console répond

Ces contrôles ne sont pas décoratifs : ce sont ceux que verifier-tuto.mjs exige de cette leçon. Ils viennent d’être joués, et voici ce qu’ils ont mesuré.

  • le lutin est à l’écran
  • il porte la tuile dessinée
  • DROITE le déplace (20 vers 44)
  • BAS aussi
  • il se pose HORS de la grille de huit (positions prises : 20, 22, 24, 26, 28, 30, 32, 34, 36, 38, 40, 42)
