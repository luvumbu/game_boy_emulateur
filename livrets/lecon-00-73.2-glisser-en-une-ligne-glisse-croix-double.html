0.73.2. Glisser en une ligne : glisse_croix — doublé, deux positions

Deux lettres, la même croix : deux appels, dans la même image.

1. Ce qu’il faut comprendre

C’est le 0.73 et le 0.73.1 réunis : deux appels, un par lettre.

Deux lutins, deux numéros (0 et 1) : ils glissent ensemble.

Les fonctions de cette leçon — et le tuto de chacune

  • #include <glisse_croix> → 0.70.3. La fonction glisse_croix() — suivre la croix, au pixel près
  • #include <ALPHABET> → 0.1.4. ALPHABET — les lettres de la police

2. Le programme, morceau par morceau

Le programme entier de la leçon, découpé comme l’œil le lit. Il fait 1179 octets de cartouche.

Ce que le compilateur y a gravé, nommé — chaque morceau, sa taille, qui l’a demandé — et ce qu’il a laissé, parce que rien ne l’appelle :

Gravé dans la cartouche :
  démarrage            70 o  ← la console, à l’allumage  — la mise en route de la console
  glisse_croix()      195 o  ← main()  — une fonction fournie par le langage
  main()               67 o  ← démarrage  — ta fonction
  VBlank                8 o  ← la console, à chaque image  — compte les images, 60 fois par seconde
  AttendreImage        28 o  ← image()  — attend l’image suivante
  AttendreVBlank       16 o  ← démarrage  — attend que l’écran soit libre
  RangerLutins         11 o  ← démarrage  — range les 40 lutins hors de l’écran
  InstallerTransfert   15 o  ← démarrage  — installe la copie des lutins en mémoire rapide
  CopierTuiles         18 o  ← démarrage  — copie les lettres et les dessins en mémoire vidéo
  LireManette          37 o  ← bouton()  — lit les huit boutons
  Tuiles              704 o  ← CopierTuiles  — la police entière
  DonneesTransfert     10 o  ← InstallerTransfert  — la petite routine qui copie les lutins
Lettres gravées : toutes (sprite() reçoit un numéro calculé)
Pas gravé (jamais appelé) : AvancerAirs, AttendreAcces, AttendreFinVBlank, AdresseCase, EffacerCases, EcrireTexte, EcrireNombre, Diviser, Reste, Multiplier, DecalerGauche, DecalerDroite, EffacerCarte, Hasard, EffacerFond, EffacerPanneau, Notes
Fonctions du langage appelées :
  sprite()       × 1    50 o sur place, dans glisse_croix()
  bouton()       × 4    20 o sur place, dans glisse_croix()  + LireManette (37 o)
  image()        × 1     6 o sur place, dans main()  + AttendreImage (28 o)
Tes fonctions appelées :
  glisse_croix() × 2    45 o sur place, dans main()

1. ce que le programme raconte de lui-même

#include <glisse_croix>   // un lutin qui suit la croix, au pixel près
#include <ALPHABET>       // les lettres de la police : ALPHABET[0] est le A

2. une variable — px

uint8_t px = 76;      // le A, en pixels

3. une variable — py

uint8_t py = 68;

4. une variable — pxb

uint8_t pxb = 20;      // le B, en pixels

5. une variable — pyb

uint8_t pyb = 20;

6. le point d’entrée : c’est ici que la console arrive

int main() {
  while (true) {
    image();
    glisse_croix(0, px, py, ALPHABET[0], 1);
    glisse_croix(1, pxb, pyb, ALPHABET[1], 1);
  }
}

3. Ce qui se passe, étape par étape

La cartouche a été compilée et exécutée pour de bon ; voici son écran aux instants qui comptent. Une image identique à la précédente n’est pas montrée — un programme qui ne bouge pas n’a qu’une seule image, et c’est la vérité sur ce programme.

4. Ce qu’on doit voir

Le A et le B suivent la croix ensemble.
