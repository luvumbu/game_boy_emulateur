0.66. La lettre bouge avec la croix

Le joueur agit, l’écran répond : c’est déjà un jeu.

1. Ce qu’il faut comprendre

bouton(DROITE) vaut vrai tant que la flèche droite est enfoncée. Même chose pour GAUCHE, HAUT et BAS.

Bouger à chaque image ferait traverser l’écran en un tiers de seconde. attente impose donc 8 images entre deux pas : en gardant la flèche enfoncée, la lettre avance d’une case environ sept fois par seconde.

Les conditions x < 19, x > 0, y < 17 et y > 0 empêchent de sortir de l’écran.

Voilà les trois ingrédients d’un jeu : la boucle, le joueur qui agit, et l’écran qui répond.

Les fonctions de cette leçon — et le tuto de chacune

  • #include <effacer> → 0.16.3. La fonction effacer() — effacer des cases
  • #include <bouton> → 0.65.5. La fonction bouton() — lire la manette
  • #include <poser> → 0.1.3. La fonction poser() — poser une tuile
  • #include <ALPHABET> → 0.1.4. ALPHABET — les lettres de la police

2. Le programme, morceau par morceau

Le programme entier de la leçon, découpé comme l’œil le lit. Il fait 393 octets de cartouche.

1. ce que le programme raconte de lui-même

#include <effacer>    // efface des cases, ou tout le fond
#include <bouton>     // lit un bouton de la manette
#include <poser>      // pose une tuile sur une case du fond
#include <ALPHABET>   // les lettres de la police : ALPHABET[0] est le A

2. une variable — x

uint8_t x = 9;        // la lettre part du milieu de l'écran

3. une variable — y

uint8_t y = 8;

4. une variable — attente

uint8_t attente = 0;  // les images à attendre avant le prochain pas

5. le point d’entrée : c’est ici que la console arrive

int main() {
  while (true) {
    image();

    if (attente > 0) attente--;

    if (attente == 0) {
      effacer(x, y, 1);                               // efface l'ancienne place
      if (bouton(DROITE) && x < 19) { x++; attente = 8; }
      if (bouton(GAUCHE) && x > 0)  { x--; attente = 8; }
      if (bouton(BAS) && y < 17)    { y++; attente = 8; }
      if (bouton(HAUT) && y > 0)    { y--; attente = 8; }
    }

    poser(x, y, ALPHABET[0]);                         // la lettre à sa place
  }
}

3. Ce qui se passe, étape par étape

La cartouche a été compilée et exécutée pour de bon ; voici son écran aux instants qui comptent. Une image identique à la précédente n’est pas montrée — un programme qui ne bouge pas n’a qu’une seule image, et c’est la vérité sur ce programme.

4. Ce que les touches changent

Chaque bouton que le programme lit a été enfoncé douze images, puis relâché. Voici l’écran juste après.

5. Ce qu’on doit voir

Un A au milieu de l’écran, qui se déplace avec les flèches.

6. Ce que la console répond

Ces contrôles ne sont pas décoratifs : ce sont ceux que verifier-tuto.mjs exige de cette leçon. Ils viennent d’être joués, et voici ce qu’ils ont mesuré.

  • le A part du milieu
  • la flèche droite le déplace
  • la flèche bas aussi
  • il est à sa nouvelle place
  • et plus au départ
