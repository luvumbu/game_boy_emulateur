0.17.2. Une lettre qui avance de 5 cases — doublé, deux positions

Le A sur la ligne 0 et le B sur la ligne 8 avancent ensemble : la même variable x pour les deux.

1. Ce qu’il faut comprendre

C’est le 0.17 et le 0.17.1 réunis : deux effacer et deux poser, un par ligne.

Une seule variable x pour les deux lettres : elles sont toujours à la même colonne, donc elles avancent ensemble, au même pas.

Les fonctions de cette leçon — et le tuto de chacune

  • #include <effacer> → 0.16.3. La fonction effacer() — effacer des cases
  • #include <poser> → 0.1.3. La fonction poser() — poser une tuile
  • #include <ALPHABET> → 0.1.4. ALPHABET — les lettres de la police

2. Le programme, morceau par morceau

Le programme entier de la leçon, découpé comme l’œil le lit. Il fait 312 octets de cartouche.

Ce que le compilateur y a gravé, nommé — chaque morceau, sa taille, qui l’a demandé — et ce qu’il a laissé, parce que rien ne l’appelle :

1. ce que le programme raconte de lui-même

#include <effacer>    // efface des cases, ou tout le fond
#include <poser>      // pose une tuile sur une case du fond
#include <ALPHABET>   // les lettres de la police : ALPHABET[0] est le A

2. une variable — pas

uint8_t pas = 5;      // le nombre de cases à parcourir

3. une variable — x

uint8_t x = 0;        // la colonne des deux lettres

4. une variable — images

uint8_t images = 0;   // le chronomètre, en images

5. le point d’entrée : c’est ici que la console arrive

int main() {
  while (true) {
    image();
    if (x < pas) {
      images++;
      if (images == 15) {
        images = 0;
        effacer(x, 0, 1);     // efface l'ancienne place, ligne 0
        effacer(x, 8, 1);     // efface l'ancienne place, ligne 8
        x++;
      }
    }
    poser(x, 0, ALPHABET[0]);   // le A, ligne 0
    poser(x, 8, ALPHABET[1]);   // le B, ligne 8
  }
}

3. Ce qui se passe, étape par étape

La cartouche a été compilée et exécutée pour de bon ; voici son écran aux instants qui comptent. Une image identique à la précédente n’est pas montrée — un programme qui ne bouge pas n’a qu’une seule image, et c’est la vérité sur ce programme.

4. Ce qu’on doit voir

Le A et le B avancent ensemble de 5 cases, l’un sur la ligne 0, l’autre sur la ligne 8.

5. Ce que la console répond

Ces contrôles ne sont pas décoratifs : ce sont ceux que verifier-tuto.mjs exige de cette leçon. Ils viennent d’être joués, et voici ce qu’ils ont mesuré.

  • le A finit en (5, 0) (5,0)
  • le B finit en (5, 8) (5,8)
