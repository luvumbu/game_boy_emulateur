0.12.1. Une lettre toutes les secondes — de base, ailleurs

Le 0.12 en colonne 10 : la lettre qui change chaque seconde, au milieu de la ligne.

1. Ce qu’il faut comprendre

C’est le 0.12, avec un seul changement : la colonne du poser : 10 au lieu de 0.

Le chronomètre ne change pas : seule la case où l’on affiche la lettre a bougé.

C’est la version de base : une seule chose, à la deuxième place. Le 0.12.2 met les deux ensemble.

2. Le programme, morceau par morceau

Le programme entier de la leçon, découpé comme l’œil le lit. Il fait 1365 octets de cartouche.

1. une constante — IMAGES_PAR_SECONDE

const uint8_t IMAGES_PAR_SECONDE = 60;

2. une constante — SECONDES

const uint8_t SECONDES = 1;

3. une variable — lettre

uint8_t lettre = 0;

4. une variable — images

uint8_t images = 0;

5. le point d’entrée : c’est ici que la console arrive

int main() {
  while (true) {
    image();
    images++;
    if (images == SECONDES * IMAGES_PAR_SECONDE) {
      images = 0;
      lettre++;
      if (lettre == sizeof(ALPHABET)) lettre = 0;
    }
    // Le changement : la colonne, 0 → 10.
    poser(10, 0, ALPHABET[lettre]);
  }
}

3. Ce qui se passe, étape par étape

La cartouche a été compilée et exécutée pour de bon ; voici son écran aux instants qui comptent. Une image identique à la précédente n’est pas montrée — un programme qui ne bouge pas n’a qu’une seule image, et c’est la vérité sur ce programme.

4. Ce qu’on doit voir

Une lettre en haut, au milieu de la ligne, qui change chaque seconde.

5. Ce que la console répond

Ces contrôles ne sont pas décoratifs : ce sont ceux que verifier-tuto.mjs exige de cette leçon. Ils viennent d’être joués, et voici ce qu’ils ont mesuré.

  • une lettre en (10, 0)
  • elle a changé depuis (A → C)
