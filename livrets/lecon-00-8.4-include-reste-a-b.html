0.8.4. #include <reste> — a % b

#include <reste> : a % b, le reste d’une division, demande une routine, sauf par 1, 2, 4, 8, 16… écrits en clair.

1. Ce qu’il faut comprendre

Ce que c’est : a % b est le reste de la division : 100 % 7 vaut 2, parce que 100 = 7 × 14 + 2. Par 2, 4, 8, 16… écrit en clair, c’est garder les bits du bas : gratuit. Sinon, il faut une routine.

La ligne à écrire : #include <reste>.

Ce qu’elle coûte : une vingtaine d’octets.

Essaie : hasard() % 6 : un nombre de 0 à 5, pour un dé.

On retrouve reste dans 42 leçons

0.9, 0.9.1, 0.9.2, 0.15, 0.15.1, 0.15.2, 0.77, 0.81.1, 0.81.3, 0.83, 0.85, 0.88.2, 0.89.2, 0.90.5, 0.91.4, 0.91.5, 0.91.6, 0.91.7, 0.91.8, 0.91.9, 0.92, 0.92.1, 0.92.2, 0.94, 0.94.1, 0.102, 0.102.1, 0.103, 0.104, 0.108, 10, 16, 31, 32, 60, 62, 94, 105, 111, 114, 115, 131

1. ce que le programme raconte de lui-même

#include <reste>     // la routine du reste
#include <nombre>

2. une variable — a

uint8_t a = 100;

3. une variable — b

uint8_t b = 7;

4. une variable — r

uint8_t r = 0;

5. le point d’entrée : c’est ici que la console arrive

int main() {
  r = a % b;            // 100 = 7 × 14 + 2 : le reste est 2
  nombre(8, 8, r);      // 002

  while (true) {
    image();
  }
}
