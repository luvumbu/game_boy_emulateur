0.104. Une lettre qui tire — un petit jeu : les W tombent

Tout ensemble, dans un petit jeu : le A, en bas, va de côté et tire vers le haut ; trois W tombent. Un W touché : un point, et il repart d’en haut. Un W arrivé en bas : une vie de moins. PERDU, et START.

1. Ce qu’il faut comprendre

Un petit jeu complet, avec tout ce qu’on a vu. Le A est en bas, sur la ligne 15, au-dessus d’un sol de « # ». Il va à gauche et à droite, et tire vers le haut. Trois W tombent du ciel, une case toutes les 600 ms. Un W touché : un point, et il repart d’en haut. Un W qui arrive en bas : une vie de moins.

Ce qui vient d’avant : le tir qui avance et regarde sa case d’arrivée (le 0.101), la cible touchée (le 0.102), trois tirs dans un tableau de struct avec chaque(250) (le 0.102.1), les vies, PERDU et START (le 0.103), les ennemis dans un tableau (le 0.85).

Plus simple qu’avant, sur deux points. Le A ne va que de côté : sa ligne est toujours 15, pas besoin de ay. Et les tirs vont toujours vers le haut : le struct Tir perd son sens (dx, dy), l’arrivée d’un tir est simplement la ligne y - 1.

Ce qui est nouveau ici (1) : plusieurs cibles. Au 0.102, une seule cible : nx == bx && ny == by. Ici, trois W : une boucle sur j compare l’arrivée du tir à chaque W. Si l’un est là : il disparaît, placerW(j) le renvoie en haut, et touche = 1. Après la boucle, touche dit si le tir a touché quelque chose.

Ce qui est nouveau ici (2) : un W ne tombe pas sur un tir. Si la case sous un W n’est pas vide (un tir, ou un autre W), le W attend : il ne descend pas à ce tour-ci. Au pas suivant du tir, c’est le tir qui monte sur lui : touché. Sans cette attente, le W écraserait le dessin du tir, et le tir, en avançant, effacerait… le W.

Arrivé en bas : quand l’arrivée d’un W est la ligne 15, celle du A, il ne s’y pose pas : il disparaît, repart d’en haut, et le joueur perd une vie.

nouvellePartie() : tout ce qu’il faut pour commencer (vider le terrain, arrêter les tirs, placer les W et le A, 3 vies, score 0) est rangé dans une fonction. On l’appelle au début et quand on appuie sur START : écrit une seule fois, fait deux fois.

Essaie : fais tomber les W plus vite (chaque(400)), ajoute un quatrième W (Ennemi ennemis[4], et j < 4 partout), ou fais accélérer la chute quand le score monte.

📖 Les mots de cette leçon — si tu débutes

  • accolades { } — Elles entourent un bloc : les lignes qui vont ensemble (le corps d’une fonction, d’une boucle, d’un « if »). Chaque « { » a son « } ».
  • affectation (=) — « x = 5; » : la boîte x prend la valeur 5. Ce n’est pas une égalité : c’est un rangement.
  • argument — Une valeur donnée à une fonction quand on l’appelle, entre ses parenthèses : dans texte(5, 8, "SALUT"), 5, 8 et "SALUT" sont les arguments.
  • bloc — Un groupe de lignes entre accolades { }, qui s’exécutent ensemble.
  • booléen (vrai / faux) — Le résultat d’une condition : vrai (1) ou faux (0). « true » veut dire vrai, « false » faux.
  • boucle — Des instructions qui se répètent : « while » (tant que…) ou « for » (pour un compteur qui va de… à…).
  • boucle du jeu — « while (true) { image(); … } » : ce qui se répète 60 fois par seconde, sans fin, pendant tout le jeu.
  • bouton() — Une fonction de la console qui dit si un bouton de la manette est enfoncé : 1 oui, 0 non. Les boutons : A, B, HAUT, BAS, GAUCHE, DROITE, START, SELECT.
  • chaîne de caractères (texte) — Des lettres entre guillemets, "COMME CECI" : un texte pris tel quel. La police de la console n’a que des majuscules, sans accents.
  • commentaire (//) — Tout ce qui suit « // » jusqu’au bout de la ligne : une phrase pour l’humain, que la console ignore.
  • condition — Une question dont la réponse est vrai ou faux : « score > 10 », « bouton(A) ». On la teste avec « if » ou « while ».
  • coordonnées — Deux nombres qui disent où : la colonne (vers la droite) puis la ligne (vers le bas), à partir de (0, 0) en haut à gauche.
  • else (sinon) — Ce que l’on fait quand la condition du « if » est fausse.
  • fonction — Un groupe d’instructions qui a un nom, qu’on lance en écrivant son nom et des parenthèses. Celles de la console (texte, poser…) sont toutes prêtes ; on peut écrire les siennes.
  • for — Une boucle qui compte : « for (uint8_t i = 0; i < 5; i++) » fait 5 tours, i valant 0, 1, 2, 3 puis 4.
  • hasard() — Une fonction de la console qui rend un nombre au hasard, de 0 à 255.
  • if (si) — Teste une condition : si elle est vraie, on fait le bloc qui suit.
  • image() — Attend l’image suivante. La console en montre 60 par seconde : c’est ce qui règle la vitesse d’un jeu.
  • #include — En haut du programme : « #include <texte> » demande la fonction texte() à la console ; « #include "fichier.cpp" » verse un de tes fichiers à cet endroit.
  • incrémenter (++) — « x++ » ou « x += 1 » : x augmente de 1. « x-- » : x diminue de 1.
  • indice — Le numéro d’une case dans un tableau, entre crochets : cases[3] est la quatrième case (on compte à partir de 0).
  • instruction — Un ordre donné à la console, terminé par un point-virgule : « texte(1, 1, "OK"); ».
  • main — « int main() { … } » : là où le programme commence. La console exécute d’abord la première ligne de main.
  • octet — Un nombre de 0 à 255 : la plus petite boîte de la mémoire. Une cartouche en a 32 768.
  • opérateurs de calcul — + plus, - moins, * fois, / divisé par (sans virgule : 7 / 2 donne 3), % le reste de la division (7 % 2 donne 1).
  • opérateurs de comparaison — == égal, != différent, < plus petit, > plus grand, <= plus petit ou égal, >= plus grand ou égal. Le résultat est vrai ou faux.
  • opérateurs logiques — && « et » (les deux doivent être vrais), || « ou » (un seul suffit), ! « pas ».
  • paramètre — Dans la définition d’une fonction, la boîte qui reçoit une valeur donnée à l’appel : dans « void f(uint8_t x) », x est un paramètre.
  • point-virgule (;) — Il termine une instruction, comme le point termine une phrase.
  • poser() — Met une tuile dans le décor, sur une case de la grille de 20 × 18 (32 × 32 en tout, avec la partie cachée).
  • struct — Un modèle qui regroupe plusieurs boîtes sous un nom : « struct Ennemi { uint8_t x; uint8_t y; }; ».
  • tableau — Une rangée de boîtes sous un même nom : « uint8_t cases[10]; » donne cases[0] à cases[9].
  • texte() — Écrit des lettres à l’écran, sur la grille de 20 colonnes et 18 lignes : texte(colonne, ligne, "MOT").
  • uint8_t — Le genre de nombre de cette console : un entier de 0 à 255 (un octet). Au-delà, il repart à 0.
  • variable — Une boîte avec un nom, dans la mémoire, qui retient un nombre qu’on peut lire et changer.
  • void — Devant une fonction : elle ne rend rien, elle agit seulement.
  • while (tant que) — Répète un bloc tant qu’une condition est vraie.

void placerW(uint8_t j) {
  do {
    ennemis[j].x = hasard() % 20;      // colonne 0 à 19…
    ennemis[j].y = 0;                  // …sur la ligne 0…
  } while (lire(ennemis[j].x, 0) != 0);  // …sur une case vide
  poser(ennemis[j].x, 0, ALPHABET[22]);
}

void nouvellePartie() {
  for (uint8_t l = 0; l < 16; l++) {   // les lignes 0 à 15 : le terrain
    effacer(0, l, 20);
  }
  for (uint8_t i = 0; i < 3; i++) {
    tirs[i].vole = 0;                  // aucun tir en vol…
    placerW(i);                        // …et les trois W en haut
  }
  ax = 9;
  poser(ax, 15, ALPHABET[0]);          // le A, en bas au milieu
  score = 0;
  vies = 3;
  nombre(6, 17, score);
  nombre(15, 17, vies);
  etat = 0;
}

        nouvellePartie();              // tout recommence
      }
    }
  }
}

3. Ce qui se passe, étape par étape

La cartouche a été compilée et exécutée pour de bon ; voici son écran aux instants qui comptent. Une image identique à la précédente n’est pas montrée — un programme qui ne bouge pas n’a qu’une seule image, et c’est la vérité sur ce programme.

4. Ce que les touches changent

Chaque bouton que le programme lit a été enfoncé douze images, puis relâché. Voici l’écran juste après.

5. Ce qu’on doit voir

Trois W tombent. Le A, en bas, va de côté et tire vers le haut : un W touché rapporte un point et repart d’en haut ; un W arrivé en bas coûte une vie. À 0 : PERDU ; START relance.

6. Ce que la console répond

Ces contrôles ne sont pas décoratifs : ce sont ceux que verifier-tuto.mjs exige de cette leçon. Ils viennent d’être joués, et voici ce qu’ils ont mesuré.

  • au départ : trois W en haut, le A en (9, 15), le sol, SCORE 000
  • en visant, le A touche des W : le score monte (score 5)
  • un W touché repart d’en haut : toujours trois W
  • sans tirer, les W arrivent en bas : les vies tombent à 0, PERDU
  • START : une nouvelle partie, 3 vies, score 0
