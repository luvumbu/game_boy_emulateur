36. Le son

Quatre voix, dont trois qu’on peut jouer.

1. Ce qu’il faut comprendre

La console a une puce sonore depuis toujours, et rien ne lui parlait. note(voix, hauteur, duree, volume) joue une note sur la voix 1 ou 2 — deux signaux carrés — et bruit(duree, volume) frappe sur la quatrième, celle du bruit : une explosion, un pas, un tir.

Les hauteurs portent des noms : DO4, RED4, MI4… de DO2 à SI6, cinq octaves. Un nom se relit ; un numéro de fréquence, non. La table est calculée à la compilation et gravée dans la cartouche — 120 octets pour tout le clavier.

La durée se compte en 256ᵉ de seconde, de 1 à 64. Une durée de 0 veut dire « sans fin » : la note tient jusqu’à silence(voix). Le volume va de 0 à 15.

Deux voix, c’est une mélodie et son accompagnement. Ici la voix 2 double la voix 1 une octave plus bas — MELODIE[pas] - 12, puisqu’une octave fait douze demi-tons.

2. Le programme, morceau par morceau

Le programme entier de la leçon, découpé comme l’œil le lit. Il fait 1583 octets de cartouche.

1. une table gravée dans la cartouche — MELODIE

const uint8_t MELODIE[] = { DO4, MI4, SOL4, DO5, SOL4, MI4, RE4, SOL4 };

2. une variable — pas

uint8_t pas = 0;

3. une variable — attente

uint8_t attente = 0;

4. le point d’entrée : c’est ici que la console arrive

int main() {
  texte(3, 5, "A POUR UN BRUIT");

  while (true) {
    image();

    attente++;

    if (attente > 24) {
      attente = 0;

      note(1, MELODIE[pas], 20, 12);
      note(2, MELODIE[pas] - 12, 20, 6);

      pas++;
      if (pas >= sizeof(MELODIE)) pas = 0;
    }

    if (bouton(A)) bruit(6, 12);
    if (bouton(START)) { silence(1); silence(2); }
  }

  return 0;
}

3. Ce qui se passe, étape par étape

La cartouche a été compilée et exécutée pour de bon ; voici son écran aux instants qui comptent. Une image identique à la précédente n’est pas montrée — un programme qui ne bouge pas n’a qu’une seule image, et c’est la vérité sur ce programme.

6. Ce que la console répond

Ces contrôles ne sont pas décoratifs : ce sont ceux que verifier-tuto.mjs exige de cette leçon. Ils viennent d’être joués, et voici ce qu’ils ont mesuré.

  • la puce sonore est allumée
  • la console produit vraiment du son (52 images sur 260)
  • la voix 1 joue le DO4 et le DO5 (262, 294, 329, 392, 524 Hz)
  • la voix 2 double une octave plus bas (131, 147, 165, 196, 262 Hz)
