0.105. Une lettre qui tire — le tir casse le X

On reprend le 0.101 (le mur de X, un seul tir) : le tir qui arrive sur un X le casse. Le X disparaît, le tir aussi ; le tir suivant passe par le trou, et le A aussi.

1. Ce qu’il faut comprendre

On revient au mur du 0.101, pour le casser. Au 0.101, le X arrêtait le tir, et restait. Ici, le tir qui arrive sur un X le casse : le X disparaît, le tir aussi. Le mur a un trou : le tir suivant passe, et le A peut y marcher.

Ce qui vient d’avant : tout le 0.101. Le A bouge et regarde (le 0.100), le tir part dans son sens, et avant chaque pas il regarde sa case d’arrivée avec lire().

Ce qui est nouveau ici : un cas de plus, « c’est un X ». Le pas du tir avait trois cas : hors de l’écran, pas vide, vide. On en ajoute un, avant « pas vide » : lire(nx, ny) == ALPHABET[23], l’arrivée est un X. Alors effacer(nx, ny, 1) efface le X, et vole = 0 : le tir s’est usé dessus, il disparaît.

Pourquoi avant « pas vide » ? Un X n’est pas vide : si « pas vide » venait d’abord, le tir s’y écraserait comme au 0.101, et le cas du X ne serait jamais regardé. Dans une suite de else if, le premier cas vrai gagne.

Déroulons : A en (2, 8), regard à droite. Bouton A : le tir va de (3, 8) à (11, 8). Pas suivant : l’arrivée (12, 8) est un X. On efface (12, 8), le tir disparaît. Bouton A encore : le tir passe (12, 8), qui est vide, et file jusqu’au bord. DROITE : le A passe aussi par le trou.

Essaie : fais que le tir traverse le X sans disparaître : dans le cas du X, remplace vole = 0; par ce que fait le cas « vide » (tx = nx; ty = ny; et le dessin). Un tir perçant !

📖 Les mots de cette leçon — si tu débutes

  • accolades { } — Elles entourent un bloc : les lignes qui vont ensemble (le corps d’une fonction, d’une boucle, d’un « if »). Chaque « { » a son « } ».
  • affectation (=) — « x = 5; » : la boîte x prend la valeur 5. Ce n’est pas une égalité : c’est un rangement.
  • argument — Une valeur donnée à une fonction quand on l’appelle, entre ses parenthèses : dans texte(5, 8, "SALUT"), 5, 8 et "SALUT" sont les arguments.
  • bloc — Un groupe de lignes entre accolades { }, qui s’exécutent ensemble.
  • booléen (vrai / faux) — Le résultat d’une condition : vrai (1) ou faux (0). « true » veut dire vrai, « false » faux.
  • boucle — Des instructions qui se répètent : « while » (tant que…) ou « for » (pour un compteur qui va de… à…).
  • boucle du jeu — « while (true) { image(); … } » : ce qui se répète 60 fois par seconde, sans fin, pendant tout le jeu.
  • bouton() — Une fonction de la console qui dit si un bouton de la manette est enfoncé : 1 oui, 0 non. Les boutons : A, B, HAUT, BAS, GAUCHE, DROITE, START, SELECT.
  • chaîne de caractères (texte) — Des lettres entre guillemets, "COMME CECI" : un texte pris tel quel. La police de la console n’a que des majuscules, sans accents.
  • commentaire (//) — Tout ce qui suit « // » jusqu’au bout de la ligne : une phrase pour l’humain, que la console ignore.
  • condition — Une question dont la réponse est vrai ou faux : « score > 10 », « bouton(A) ». On la teste avec « if » ou « while ».
  • coordonnées — Deux nombres qui disent où : la colonne (vers la droite) puis la ligne (vers le bas), à partir de (0, 0) en haut à gauche.
  • else (sinon) — Ce que l’on fait quand la condition du « if » est fausse.
  • for — Une boucle qui compte : « for (uint8_t i = 0; i < 5; i++) » fait 5 tours, i valant 0, 1, 2, 3 puis 4.
  • if (si) — Teste une condition : si elle est vraie, on fait le bloc qui suit.
  • image() — Attend l’image suivante. La console en montre 60 par seconde : c’est ce qui règle la vitesse d’un jeu.
  • #include — En haut du programme : « #include <texte> » demande la fonction texte() à la console ; « #include "fichier.cpp" » verse un de tes fichiers à cet endroit.
  • incrémenter (++) — « x++ » ou « x += 1 » : x augmente de 1. « x-- » : x diminue de 1.
  • indice — Le numéro d’une case dans un tableau, entre crochets : cases[3] est la quatrième case (on compte à partir de 0).
  • instruction — Un ordre donné à la console, terminé par un point-virgule : « texte(1, 1, "OK"); ».
  • main — « int main() { … } » : là où le programme commence. La console exécute d’abord la première ligne de main.
  • octet — Un nombre de 0 à 255 : la plus petite boîte de la mémoire. Une cartouche en a 32 768.
  • opérateurs de calcul — + plus, - moins, * fois, / divisé par (sans virgule : 7 / 2 donne 3), % le reste de la division (7 % 2 donne 1).
  • opérateurs de comparaison — == égal, != différent, < plus petit, > plus grand, <= plus petit ou égal, >= plus grand ou égal. Le résultat est vrai ou faux.
  • opérateurs logiques — && « et » (les deux doivent être vrais), || « ou » (un seul suffit), ! « pas ».
  • point-virgule (;) — Il termine une instruction, comme le point termine une phrase.
  • poser() — Met une tuile dans le décor, sur une case de la grille de 20 × 18 (32 × 32 en tout, avec la partie cachée).
  • texte() — Écrit des lettres à l’écran, sur la grille de 20 colonnes et 18 lignes : texte(colonne, ligne, "MOT").
  • uint8_t — Le genre de nombre de cette console : un entier de 0 à 255 (un octet). Au-delà, il repart à 0.
  • variable — Une boîte avec un nom, dans la mémoire, qui retient un nombre qu’on peut lire et changer.
  • while (tant que) — Répète un bloc tant qu’une condition est vraie.

#include <poser>      // pose une tuile sur une case du fond
#include <ALPHABET>   // les lettres de la police : ALPHABET[0] est le A
#include <chaque>     // répond 1 toutes les n millisecondes
#include <bouton>     // lit un bouton de la manette
#include <lire>       // lit la tuile posée sur une case
#include <effacer>    // efface des cases, ou tout le fond
#include <texte>      // écrit un texte à l’écran

2. une variable — ax

uint8_t ax = 2;              // le A : sa colonne…

3. une variable — ay

uint8_t ay = 8;              // …et sa ligne

4. une variable — dx

uint8_t dx = 1;              // le sens où regarde le A (le 0.100)

5. une variable — dy

uint8_t dy = 0;

6. une variable — nx

uint8_t nx = 0;              // une case d'ARRIVÉE, calculée avant de bouger

7. une variable — ny

uint8_t ny = 0;

8. une variable — tx

uint8_t tx = 0;              // le tir : sa place…

9. une variable — ty

uint8_t ty = 0;

10. une variable — tdx

uint8_t tdx = 0;             // …et son sens

11. une variable — tdy

uint8_t tdy = 0;

12. une variable — vole

uint8_t vole = 0;            // 1 = le tir est en vol ; 0 = pas de tir

13. le point d’entrée : c’est ici que la console arrive

int main() {
  // ---- NOUVEAU : un mur de X, debout, en colonne 12, des lignes 4 à 12 ----
  for (uint8_t l = 4; l < 13; l++) {   // l vaut 4, 5, 6… jusqu'à 12 : 9 X
    poser(12, l, ALPHABET[23]);
  }
  poser(ax, ay, ALPHABET[0]);

  while (true) {
    image();

    // ---- le A bouge et retient où il regarde (le 0.100) ----
    // Il ne va que sur une case vide : le mur l'arrête déjà.
    if (chaque(150)) {
      nx = ax;
      ny = ay;
      if (bouton(DROITE)) {
        nx = ax + 1;
        dx = 1;
        dy = 0;
      } else if (bouton(GAUCHE)) {
        nx = ax - 1;
        dx = -1;
        dy = 0;
      } else if (bouton(BAS)) {
        ny = ay + 1;
        dx = 0;
        dy = 1;
      } else if (bouton(HAUT)) {
        ny = ay - 1;
        dx = 0;
        dy = -1;
      }
      if (nx < 20 && ny < 17) {
        if (lire(nx, ny) == 0) {
          effacer(ax, ay, 1);
          ax = nx;
          ay = ny;
          poser(ax, ay, ALPHABET[0]);
        }
      }
    }

    // ---- A lance le tir ----
    if (bouton(A) && vole == 0) {
      nx = ax + dx;
      ny = ay + dy;
      // NOUVEAU : la case de départ doit aussi être VIDE.
      // Collé au mur, le A ne tire pas : le tir n'a pas de place.
      if (nx < 20 && ny < 17 && lire(nx, ny) == 0) {
        vole = 1;
        tx = nx;
        ty = ny;
        tdx = dx;
        tdy = dy;
        texte(tx, ty, ".");
      }
    }

    // ---- le tir avance ; il regarde sa case d'arrivée AVANT d'y aller ----
    if (chaque(100)) {
      if (vole == 1) {
        nx = tx + tdx;
        ny = ty + tdy;
        effacer(tx, ty, 1);
        if (nx >= 20 || ny >= 17) {
          vole = 0;                  // 1. hors de l'écran : il disparaît
        } else if (lire(nx, ny) == ALPHABET[23]) {
          // 2. NOUVEAU : l'arrivée est un X : le tir le CASSE.
          effacer(nx, ny, 1);        //    le X disparaît (sa case devient vide)…
          vole = 0;                  //    …et le tir aussi : il s'est usé dessus.
        } else if (lire(nx, ny) != 0) {
          vole = 0;                  // 3. autre chose, pas vide : il s'écrase.
        } else {
          tx = nx;                   // 4. l'arrivée est vide : il y va
          ty = ny;
          texte(tx, ty, ".");
        }
        // L'ordre compte : d'abord « hors de l'écran ? », car lire(20, 8)
        // n'a pas de sens : la case n'existe pas.
      }
    }
  }
}

3. Ce qui se passe, étape par étape

La cartouche a été compilée et exécutée pour de bon ; voici son écran aux instants qui comptent. Une image identique à la précédente n’est pas montrée — un programme qui ne bouge pas n’a qu’une seule image, et c’est la vérité sur ce programme.

4. Ce que les touches changent

Chaque bouton que le programme lit a été enfoncé douze images, puis relâché. Voici l’écran juste après.

5. Ce qu’on doit voir

Le tir casse le X de la ligne 8 et disparaît ; le tir suivant passe par le trou jusqu’au bord, et le A peut y marcher. Les autres X restent.

6. Ce que la console répond

Ces contrôles ne sont pas décoratifs : ce sont ceux que verifier-tuto.mjs exige de cette leçon. Ils viennent d’être joués, et voici ce qu’ils ont mesuré.

  • au départ, un X en (12, 8)
  • le premier tir le casse : (12, 8) est vide, les X au-dessus et au-dessous restent
  • le tir suivant passe par le trou, jusqu’en colonne 19 (le plus loin : colonne 19)
  • le A passe par le trou, lui aussi
