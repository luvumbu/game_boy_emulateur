0.83.1. La fonction bruit() — un bruit

#include <bruit> : bruit(duree, volume) frappe sur la voix du bruit : un tir, un pas, une explosion.

1. Ce qu’il faut comprendre

Ce qu’elle fait : bruit(duree, volume) frappe sur la voix 4, celle du bruit : pas une note, un choc. Un troisième argument, le grain (0 à 255), le rend plus sourd ou plus sifflant.

La ligne à écrire : #include <bruit>.

Ses arguments : la durée (1 à 64, ou 0 : sans fin), le volume (0 à 15), et le grain, facultatif.

Ce qu’elle coûte : environ 50 octets.

Essaie : bruit(20, 8, 0x55); : plus rêche.

On retrouve bruit dans 6 leçons

0.83.2, 0.103, 0.104, 53, 57, 122

2. Le programme, morceau par morceau

Le programme entier de la leçon, découpé comme l’œil le lit. Il fait 451 octets de cartouche.

1. ce que le programme raconte de lui-même

// ---- #include <bruit> : un bruit ----
// Chaque fois qu'on appuie sur A, un bruit court.

#include <bruit>     // bruit() : la voix du bruit
#include <bouton>
#include <texte>

2. le point d’entrée : c’est ici que la console arrive

int main() {
  texte(4, 8, "APPUIE SUR A");

  while (true) {
    image();
    if (bouton(A)) {
      bruit(10, 12);      // court (10), fort (12)
    }
  }
}
