0.78.1. Le rebond : une vitesse qui change de signe — en diagonale

Le 0.78 sur les deux axes : vx ET vy. La balle rebondit sur les quatre bords.

1. Ce qu’il faut comprendre

C’est le 0.78, sur les deux axes : une vitesse vy pour la ligne, en plus de vx pour la colonne.

Ce qui est nouveau ici : deux vitesses. À chaque pas, x = x + vx; et y = y + vy; : la balle va en diagonale. Chaque axe rebondit à part : aux bords gauche et droit, vx change de signe ; en haut et en bas, vy.

La balle part de (0, 0) et ne s’arrête jamais : elle rebondit dans tout l’écran (lignes 0 à 16, pour laisser la ligne 17 libre).

Les fonctions de cette leçon — et le tuto de chacune

  • #include <chaque> → 0.29.3. La fonction chaque() — toutes les n millisecondes
  • #include <effacer> → 0.16.3. La fonction effacer() — effacer des cases
  • #include <poser> → 0.1.3. La fonction poser() — poser une tuile
  • #include <ALPHABET> → 0.1.4. ALPHABET — les lettres de la police

1. ce que le programme raconte de lui-même

#include <chaque>     // répond 1 toutes les n millisecondes
#include <effacer>    // efface des cases, ou tout le fond
#include <poser>      // pose une tuile sur une case du fond
#include <ALPHABET>   // les lettres de la police : ALPHABET[0] est le A

2. une variable — x

uint8_t x = 0;        // la colonne de la balle

3. une variable — y

uint8_t y = 0;        // sa ligne

4. une variable — vx

uint8_t vx = 1;       // vitesse en colonne : 1 à droite, -1 à gauche

5. une variable — vy

uint8_t vy = 1;       // vitesse en ligne   : 1 en bas,   -1 en haut

6. le point d’entrée : c’est ici que la console arrive

int main() {
  while (true) {
    image();
    if (chaque(50)) {
      effacer(x, y, 1);
      x = x + vx;                     // un pas en diagonale :
      y = y + vy;                     // une colonne ET une ligne
      if (x == 19) { vx = -1; }       // les bords gauche et droit : vx
      if (x == 0)  { vx = 1; }
      if (y == 16) { vy = -1; }       // les bords haut et bas : vy
      if (y == 0)  { vy = 1; }
      poser(x, y, ALPHABET[14]);
    }
  }
}

3. Ce qui se passe, étape par étape

La cartouche a été compilée et exécutée pour de bon ; voici son écran aux instants qui comptent. Une image identique à la précédente n’est pas montrée — un programme qui ne bouge pas n’a qu’une seule image, et c’est la vérité sur ce programme.

4. Ce qu’on doit voir

Un O qui rebondit en diagonale sur les quatre bords de l’écran.

5. Ce que la console répond

Ces contrôles ne sont pas décoratifs : ce sont ceux que verifier-tuto.mjs exige de cette leçon. Ils viennent d’être joués, et voici ce qu’ils ont mesuré.

  • il touche le bas (16)
  • et le bord droit (19)
  • toujours en diagonale : x et y changent ensemble
