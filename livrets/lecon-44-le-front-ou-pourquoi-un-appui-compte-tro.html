44. Le front, ou pourquoi un appui compte trois fois

Agir au moment précis où le bouton s’enfonce.

1. Ce qu’il faut comprendre

Un jeu tourne à soixante images par seconde. Un appui dure au moins cinq images : lu au niveau, il compte cinq fois. Sur un menu, on traverse trois lignes sans rien voir.

La réponse tient en une variable : l’état du bouton à l’image précédente. On agit quand il vaut 1 maintenant et valait 0 avant — ce qu’on appelle agir au front.

Le programme montre les deux compteurs côte à côte. Tiens A : celui du haut s’emballe, celui du bas monte d’un seul cran.

Les fonctions de cette leçon — et le tuto de chacune

  • #include <texte> → 0.0.2. La fonction texte() — écrire un mot
  • #include <bouton> → 0.65.5. La fonction bouton() — lire la manette
  • #include <poser> → 0.1.3. La fonction poser() — poser une tuile

2. Le programme, morceau par morceau

Le programme entier de la leçon, découpé comme l’œil le lit. Il fait 1030 octets de cartouche.

Ce que le compilateur y a gravé, nommé — chaque morceau, sa taille, qui l’a demandé — et ce qu’il a laissé, parce que rien ne l’appelle :

1. ce que le programme raconte de lui-même

#include <texte>    // écrit un texte à l’écran
#include <bouton>   // lit un bouton de la manette
#include <poser>    // pose une tuile sur une case du fond

2. le point d’entrée : c’est ici que la console arrive

int main() {
  uint8_t aAvant = 0;
  uint8_t niveau = 0;
  uint8_t front = 0;

  texte(1, 4, "NIVEAU");
  texte(1, 8, "FRONT");

  while (true) {
    image();

    uint8_t a = bouton(A);

    if (a && niveau < 9) niveau++;
    if (a && !aAvant && front < 9) front++;

    aAvant = a;

    poser(10, 4, 27 + niveau);
    poser(10, 8, 27 + front);
  }

  return 0;
}

3. Ce qui se passe, étape par étape

La cartouche a été compilée et exécutée pour de bon ; voici son écran aux instants qui comptent. Une image identique à la précédente n’est pas montrée — un programme qui ne bouge pas n’a qu’une seule image, et c’est la vérité sur ce programme.

4. Ce que les touches changent

Chaque bouton que le programme lit a été enfoncé douze images, puis relâché. Voici l’écran juste après.

5. Ce qu’on doit voir

Un appui sur A : le compteur « NIVEAU » saute, « FRONT » avance d’un.

6. Ce que la console répond

Ces contrôles ne sont pas décoratifs : ce sont ceux que verifier-tuto.mjs exige de cette leçon. Ils viennent d’être joués, et voici ce qu’ils ont mesuré.

  • le niveau compte plusieurs fois (8 pour un seul appui)
  • le front ne compte qu’une fois
  • un second appui donne deux
